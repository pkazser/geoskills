# AL00-R — Προαιρετικός επανέλεγχος μετά από περίπου επτά ημέρες

*Διάρκεια: 10–12 λεπτά. Δεν συμπεριλαμβάνεται στα 195 λεπτά.*

Μην ανοίξεις chatbot, προηγούμενο φύλλο εργασίας ή το εγχειρίδιο πριν από την πρώτη προσπάθεια. Πρόκειται για **διαμορφωτικό επανέλεγχο**, όχι για τυπική ερευνητική απόδειξη αποτελεσματικότητας.

**Δοκιμή 1 — Νέα στατιστική εφαρμογή.** Χρόνοι: **6, 8, 8, 9, 34** λεπτά. Βρες μέσο όρο και διάμεσο, εξήγησε την επίδραση της μεγάλης τιμής και προβλέψε τι αλλάζει αν το 34 γίνει 44. Έπειτα επαλήθευσε αριθμητικά.

**Δοκιμή 2 — ΤΝ και αξιοπιστία.** Σε τρεις προτάσεις εξήγησε γιατί μια πειστική βιβλιογραφική αναφορά chatbot μπορεί να απαιτεί επαλήθευση και πού θα την έλεγες.

**Δοκιμή 3 — Μαθησιακή στρατηγική.** Με μία σύντομη παράγραφο περιέγραψε τι θα έκανες όταν μια νέα έννοια σε δυσκολεύει, ώστε να μη μεταβιβάσεις όλη την προσπάθεια στην ΤΝ.

Μετά τις απαντήσεις, συμβουλέψου την τεκμηριωμένη πηγή για τα μέτρα κεντρικής τάσης [8] και τις σημειώσεις σου. Κατάγραψε τι θυμήθηκες, τι ξέχασες και τι θα επαναλάβεις. Αν συμμετέχεις σε πιλοτική μελέτη, ακολούθησε τις ειδικές οδηγίες του εκπαιδευτή για τη συλλογή και προστασία των δεδομένων.

# Μικρό γλωσσάρι

| Όρος | Σύντομη σημασία |
|---|---|
| Artificial Intelligence (AI) | Ευρύ πεδίο και συστήματα που από εισόδους παράγουν προβλέψεις, περιεχόμενο, συστάσεις ή αποφάσεις. |
| Machine Learning (ML) | Προσέγγιση ΤΝ που χρησιμοποιεί δεδομένα για προσαρμογή παραμέτρων μοντέλου. |
| Deep Learning (DL) | Μηχανική Μάθηση με πολυεπίπεδα τεχνητά νευρωνικά δίκτυα. |
| Generative AI | Συστήματα που παράγουν νέο περιεχόμενο, όπως κείμενο ή εικόνα. |
| LLM | Μεγάλο γλωσσικό μοντέλο που επεξεργάζεται και παράγει γλωσσικές ακολουθίες. |
| Prompt | Ερώτηση, οδηγία ή σύνολο εισόδων προς ένα σύστημα ΤΝ. |
| Token | Μονάδα επεξεργασίας κειμένου· δεν ισοδυναμεί πάντα με λέξη. |
| Context / context window | Διαθέσιμα συμφραζόμενα / τεχνικό όριο διαθέσιμου πλαισίου. |
| Inference | Χρήση ήδη εκπαιδευμένου μοντέλου για παραγωγή αποτελέσματος. |
| Overfitting | Υπερβολική προσαρμογή στην εκπαίδευση με χαμηλότερη γενίκευση. |
| Hallucination / confabulation | Παραγωγή αληθοφανούς αλλά λανθασμένου ή επινοημένου περιεχομένου. |
| RAG | Παραγωγή απάντησης ενισχυμένη με ανάκτηση σχετικού εξωτερικού περιεχομένου. |
| Retrieval practice | Ενεργητική προσπάθεια ανάκλησης γνώσης χωρίς να βλέπουμε την απάντηση. |
| Metacognition | Παρακολούθηση και αξιολόγηση της ίδιας της διαδικασίας σκέψης και μάθησης. |

# Βιβλιογραφία και πηγές

**Σημείωση παιδαγωγικής τεκμηρίωσης:** Το πλαίσιο δεξιοτήτων της UNESCO και οι οδηγίες του EEF έχουν σχεδιαστεί κυρίως για σχολική εκπαίδευση· εδώ προσαρμόζονται εννοιολογικά στην τριτοβάθμια εκπαίδευση, χωρίς να υπονοείται εμπειρική επικύρωση του AL00. Οι αναφορές στον OECD και στο NIST υποστηρίζουν τεχνολογικούς ορισμούς και κινδύνους· οι Dunlosky et al. και EEF υποστηρίζουν γενικές στρατηγικές μάθησης, όχι ότι η συγκεκριμένη διαδρομή AL00 ή κάθε chatbot έχει αποδεδειγμένη αποτελεσματικότητα. Τα μαθησιακά αποτελέσματα του AL00 θα χρειαστούν πιλοτικό έλεγχο με πραγματικούς εκπαιδευόμενους.
