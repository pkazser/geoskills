# Field Surveying Core

**Σχεδιαζόμενη εκπαιδευτική διαδρομή για γεωδαιτικό σταθμό και GNSS.**

Η κεντρική διαδικασία θα είναι: **Προετοιμάζω → Στήνω → Προσανατολίζω → Μετρώ → Ελέγχω → Καταγράφω → Μεταφέρω → Επαληθεύω.**

Το εκπαιδευτικό υλικό θα δημοσιεύεται σταδιακά, αφού ελεγχθεί.
