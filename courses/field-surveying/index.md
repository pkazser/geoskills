# Field Surveying Core

Η διαδρομή Field Surveying Core εισάγει την προετοιμασία μιας μικρής τοπογραφικής αποτύπωσης με γεωδαιτικό σταθμό και GNSS. Η έκδοση FS00 είναι **τοπική υποψήφια έκδοση v0.4 προς αξιολόγηση**· δεν αποτελεί ακόμη εγκεκριμένη διαδικασία ανεξάρτητων πραγματικών μετρήσεων.

Η κεντρική διαδικασία είναι: **Προετοιμάζω → Στήνω → Προσανατολίζω → Μετρώ → Ελέγχω → Καταγράφω → Μεταφέρω → Επαληθεύω.**

## Διαθέσιμη ενότητα

- [FS00 — Πριν βγω στο πεδίο: εξοπλισμός, μετρήσεις και έλεγχοι](fs00/index.md)

Η FS00 περιλαμβάνει οκτώ υποενότητες, συνθετικό κοινό σενάριο, δραστηριότητες, κρυμμένες ενδεικτικές απαντήσεις και εμφανώς σημειωμένα SVG υποκατάστατα όπου εκκρεμεί πραγματική φωτογραφία. Η πρακτική επαφή με όργανα γίνεται μόνο με επίβλεψη διδάσκοντα.
