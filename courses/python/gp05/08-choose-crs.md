# 8. Επιλογή CRS για τη δουλειά

## Τι θα μάθεις

Θα αιτιολογείς την επιλογή CRS αντί να αντιγράφεις έναν κωδικό μηχανικά.

## Τι πρόβλημα λύνουμε

Η επιλογή CRS είναι απόφαση ανάλυσης. Το ίδιο dataset μπορεί να χρειάζεται διαφορετικό CRS για web map και διαφορετικό για τοπικές μετρήσεις.

## Κανόνας εργασίας

Για αποθήκευση longitude/latitude και διαμοιρασμό στο web, το EPSG:4326 είναι συχνή επιλογή. Για τοπικές μετρήσεις στην Ελλάδα, το EPSG:2100 είναι πρακτική επιλογή. Για μεγάλη περιοχή ή ακριβή γεωδαιτική εργασία μπορεί να χρειάζεται άλλη προβολή.

## Εφαρμογή

Κράτησε `gdf` ως source σε 4326 και δημιούργησε `projected` σε 2100 για μέτρηση. Έτσι δεν χάνεις το αρχικό dataset και κάθε βήμα έχει καθαρό ρόλο.

## QA / checkpoint

Γράψε για κάθε output CRS, μονάδες, χρήση και bounds. Έλεγξε ότι η επιλογή είναι ίδια σε όλες τις σχετικές layers. Ένα spatial join ή overlay με διαφορετικά CRS δεν πρέπει να ξεκινά χωρίς πρώτα να τα ευθυγραμμίσεις.

## GeoTip

Το “κατάλληλο” CRS εξαρτάται από περιοχή, σκοπό και ακρίβεια. Το EPSG:2100 είναι παιδαγωγικά κατάλληλο εδώ επειδή το dataset είναι ελληνικό και μικρής κλίμακας.

Πριν από spatial join, overlay, distance ή buffer, όλα τα σχετικά layers πρέπει να έχουν συμβατό CRS. Πριν από measurement πρέπει να ελέγξεις και τις μονάδες. Η επιλογή είναι απόφαση workflow: source geographic CRS για αποθήκευση/διαμοιρασμό, κατάλληλο projected CRS για τοπική ανάλυση, και διαφορετικό CRS μόνο όταν τεκμηριώνεται από την περιοχή και το ζητούμενο.
