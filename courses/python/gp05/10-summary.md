# 10. Readiness checkpoint

## Τι πρέπει να μπορείς να εξηγήσεις

- Τι πληροφορία δίνει ένα CRS και γιατί δεν είναι προαιρετική.
- Γιατί το EPSG:4326 χρησιμοποιεί μοίρες και το EPSG:2100 μέτρα.
- Πότε χρησιμοποιείς `set_crs` και πότε `to_crs`.
- Πώς τα bounds, οι μονάδες και οι geometry types λειτουργούν ως QA.

## Τελικός έλεγχος

Πάρε το `greek_sites.csv`, δημιούργησε σωστά το GeoDataFrame και γράψε ένα export για web χρήση και ένα για μέτρηση. Κράτησε τα δύο CRS ρητά ονομασμένα.

## Συχνά λάθη

Μην αλλάζεις CRS με `set_crs` για να “διορθώσεις” μονάδες. Μην κάνεις απόσταση πριν βεβαιωθείς ότι το CRS είναι projected και σε κατάλληλη περιοχή.

Το CRS είναι υπόθεση που πρέπει να τεκμηριώνεται, όχι απλώς ένας κωδικός που “υπάρχει”. Για web map μπορεί να κρατήσεις 4326· για τοπικές μετρήσεις στην Ελλάδα μπορεί να χρησιμοποιήσεις 2100, αφού ελέγξεις ότι ταιριάζει στην περιοχή και στον σκοπό. Οι μονάδες του CRS θα καθορίσουν την αξιοπιστία των measurements στο GP07.

## Μετάβαση
