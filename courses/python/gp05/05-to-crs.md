# 5. `to_crs`: πραγματικός μετασχηματισμός

## Τι θα μάθεις

Θα μετασχηματίζεις γεωμετρίες από το αρχικό CRS σε CRS κατάλληλο για τη δουλειά σου.

## Η διαδικασία

```python
projected = gdf.to_crs("EPSG:2100")
```

Το GeoPandas χρησιμοποιεί το αρχικό CRS ως αφετηρία και υπολογίζει νέες συντεταγμένες. Το αρχικό `gdf` παραμένει ως έχει, εκτός αν αναθέσεις το αποτέλεσμα ξανά.

## Τι αλλάζει και τι μένει

Αλλάζουν οι numeric coordinates και συνήθως τα bounds. Παραμένουν τα rows, τα IDs και η αντιστοίχιση geometry-feature. Αν το αρχικό CRS ήταν λάθος, το `to_crs` θα παράγει συνεπή αλλά λανθασμένο αποτέλεσμα.

## Εφαρμογή στο dataset

Μετέτρεψε τις πέντε πόλεις σε Greek Grid και εμφάνισε `name`, `geometry`. Παρατήρησε ότι το σημείο της Αθήνας έχει πλέον μεγάλες τιμές x/y σε μέτρα.

## QA

Έλεγξε ίδιο πλήθος rows, μη κενές geometry, geometry type `Point`, και νέο CRS `EPSG:2100`. Τα bounds πρέπει να είναι αριθμητικά σε κλίμακα εκατοντάδων χιλιάδων. Αν είναι ακόμη 23 και 38, δεν μετασχημάτισες.

## Checkpoint

Ποιο θα χρησιμοποιούσες για web map και ποιο για απόσταση; Γράψε μία πρόταση για το καθένα.

Το `to_crs()` αλλάζει coordinate values, bounds και units, αλλά όχι το πραγματικό αντικείμενο στον κόσμο, τα rows ή τα βασικά attributes. Χρειάζεται ήδη σωστό source CRS. Αν το source metadata είναι λάθος, η reprojection δεν διορθώνει την υπόθεση· τη μεταφέρει σε νέο CRS.
