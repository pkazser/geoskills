# 2. Μήκος γραμμών

## Τι θα μάθεις

Θα χρησιμοποιείς `.length` σε projected LineString geometry.

## Κώδικας

## Νοητικό μοντέλο

Το `.length` αθροίζει τα τμήματα μιας LineString και επιστρέφει αριθμό στις μονάδες του CRS. Το νέο field είναι attribute της ίδιας geometry, όχι νέα γραμμή.

```python
routes_m["length_m"] = routes_m.geometry.length
routes_m["length_km"] = routes_m["length_m"] / 1_000
```

Το GeoPandas αθροίζει τα τμήματα της γραμμής. Επειδή το CRS είναι EPSG:2100, το αποτέλεσμα είναι μέτρα.

## Πρακτική

Υπολόγισε μήκος για τις δύο routes και εμφάνισε `route_id`, `length_m`, `length_km`. Η μετατροπή σε km είναι απλή διαίρεση, αλλά το όνομα της στήλης πρέπει να δηλώνει τη μονάδα.

## QA / λάθη

Έλεγξε `length_m > 0`, geometry type `LineString` και λογική τάξη μεγέθους. Το `.length` σε geographic CRS επιστρέφει αριθμό σε μοίρες και δεν πρέπει να παρουσιαστεί ως μέτρα.

Το `geometry.length` επιστρέφει μία τιμή ανά LineString στις μονάδες του CRS. Σε projected CRS σε metres, δημιούργησε `length_km = length_m / 1000`. Η μέτρηση είναι γεωμετρικό μήκος της γραμμής, όχι απαραίτητα μήκος πραγματικού δρόμου με όλες τις καμπύλες ή διαδρομές.
