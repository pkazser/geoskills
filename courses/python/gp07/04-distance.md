# 4. Απόσταση μεταξύ features

## Τι θα μάθεις

Θα υπολογίζεις την απόσταση δύο σημείων.

## Κώδικας

## Πρόσεξε τη γεωμετρία

Η `distance` συγκρίνει τις δύο geometries στο ίδιο CRS. Πριν καλέσεις τη μέθοδο, βεβαιώσου ότι τα points είναι non-empty και ότι source/target layers έχουν συμβατό CRS.

```python
p01 = sites_m.geometry.iloc[0]
p02 = sites_m.geometry.iloc[1]
distance_m = p01.distance(p02)
```

Η `distance` επιστρέφει την ευκλείδεια απόσταση στις μονάδες του CRS. Για τα σημεία του GP07 είναι μέτρα.

## Πρακτική / αναμενόμενο αποτέλεσμα

Μετέτρεψε και εμφάνισε την απόσταση σε km. Θα είναι λίγα km, επειδή τα σημεία απέχουν μικρή απόσταση στην περιοχή των routes.

## QA

Έλεγξε ότι τα σημεία είναι `Point`, το CRS είναι 2100, η απόσταση θετική και μικρότερη από ένα λογικό όριο για το dataset. Μην εμπιστεύεσαι μόνο το output χωρίς bounds.

Η `distance` είναι η μικρότερη ευκλείδεια/γεωμετρική απόσταση μεταξύ δύο geometries. Μπορείς να τη μετρήσεις από ένα feature προς reference feature ή ανάμεσα σε δύο rows. Δεν είναι network distance, χρόνος ταξιδιού ή απόσταση οδικής διαδρομής· αυτά χρειάζονται διαφορετικό μοντέλο.
