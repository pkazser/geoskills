# 10. Readiness checkpoint

## Πρέπει να μπορείς να εξηγήσεις

- Γιατί οι μετρήσεις εξαρτώνται από το CRS.
- Πότε χρησιμοποιείς `.length`, `.area` και `.distance`.
- Πώς μετατρέπεις m σε km και m² σε ha.
- Πώς κάνεις sanity checks και κρατάς τις μονάδες στα field names.
- Πώς εξάγεις measured layers χωρίς να χάσεις attributes ή CRS.

## Τελική άσκηση

Τροποποίησε το workflow ώστε να προσθέτει ένα `measurement_ready` report με rows, CRS, min/max measurement και bounds για κάθε layer.

Η μετάβαση στο GP08 είναι φυσική: αφού επέλεξες features και μέτρησες geometry, θα χρησιμοποιήσεις απόσταση για να μοντελοποιήσεις νέες ζώνες εγγύτητας με buffers.

## Μετάβαση

Με GP05–GP07 έχεις πλέον ασφαλή βάση για CRS, επιλογή features και μετρήσεις. Το επόμενο module μπορεί να συνδυάσει αυτά τα βήματα σε μεγαλύτερο workflow.
