## Ερμηνεία

Η ταξινόμηση βοηθά να συνδέσεις αριθμούς με features και map. Δεν συγκρίνουμε area και length σαν να είναι ίδια ποσότητα· συγκρίνουμε features μέσα στην ίδια κατηγορία και με ίδιες μονάδες.

Χρησιμοποίησε `sort_values` για να βρεις τη μεγαλύτερη περιοχή και τη μακρύτερη route. Έλεγξε αν τα features που φαίνονται γειτονικά στον χάρτη έχουν και λογική απόσταση.

```python
areas_m.sort_values("area_ha", ascending=False)
routes_m.sort_values("length_km", ascending=False)
```

## Checkpoint

Γράψε μία πρόταση που συνδέει τη γεωμετρική εικόνα με τον αριθμητικό πίνακα.

Η σύγκριση γίνεται ευκολότερη όταν οι μετρήσεις είναι columns: ταξινόμησε για να βρεις μεγαλύτερο area/length ή μικρότερη distance και σύνδεσε το αποτέλεσμα με το GP06 filtering. Πρόσεξε να συγκρίνεις ίδια μονάδα και ίδια γεωμετρική έννοια.
