# GP07 — Measurements

Το GP07 μετατρέπει τη γεωμετρία σε μετρήσιμα μεγέθη. Ακολουθούμε **Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω** και μετράμε μόνο αφού επιλέξουμε κατάλληλο projected CRS.

## Τι θα μάθεις

Θα υπολογίζεις μήκος, εμβαδόν και απόσταση, θα μετατρέπεις m² σε hectares και m σε km, θα κάνεις sanity checks και θα αποθηκεύεις measurement fields. Τα δεδομένα βρίσκονται στο `../../../downloads/python/data/gp07/`: polygons περιοχών, routes και σημεία.

Υπολόγισε area/length/distance, έλεγξε τις τάξεις μεγέθους και κάνε export layers με νέα πεδία. Είσαι έτοιμος για το επόμενο επίπεδο όταν μπορείς να εξηγήσεις γιατί κάθε μέτρηση έγινε σε συγκεκριμένο CRS.
