## Τι είναι η Python;

Η **Python** είναι μία γλώσσα προγραμματισμού που χρησιμοποιείται ευρέως:

- στην ανάλυση δεδομένων,
- στη Γεωπληροφορική,
- στην Τηλεπισκόπηση,
- στην Τεχνητή Νοημοσύνη,
- στην αυτοματοποίηση εργασιών,
- στην επιστημονική έρευνα.

Στο GeoPython Skill Path δεν μας ενδιαφέρει να μάθουμε «όλη την Python».

Θέλουμε να μάθουμε ακριβώς όσα χρειαζόμαστε για να λύνουμε πραγματικά γεωχωρικά προβλήματα.

> 💡 **GeoTip**
>
> Η Python δεν αντικαθιστά το GIS.
> Συμπληρώνει το GIS και μας επιτρέπει να αυτοματοποιούμε, να ελέγχουμε και να επαναλαμβάνουμε εργασίες με συνέπεια.

## Γιατί Python στη Γεωπληροφορική;

Φαντάσου ότι έχεις:

- 100 αρχεία GeoPackage,
- 500 shapefiles,
- χιλιάδες σημεία,
- πολλές επαναλαμβανόμενες εργασίες,

Μέσα από ένα GIS μπορείς να κάνεις πολλές από αυτές τις εργασίες χειροκίνητα.

Παράδειγμα:

```python

```

Η Python εκτελεί την εντολή και εμφανίζει:

```text
GeoPython
```

## Τι είναι το Google Colab;

Το **Google Colab** είναι ένα περιβάλλον στο οποίο μπορούμε να γράφουμε και να εκτελούμε Python μέσα από τον browser.

Για τις πρώτες ενότητες είναι ιδανικό επειδή:

- δεν χρειάζεται εγκατάσταση Python,
- δεν χρειάζεται ρύθμιση περιβάλλοντος,
- λειτουργεί μέσα από browser,
- υποστηρίζει Jupyter Notebooks,
- μπορούμε εύκολα να μοιραζόμαστε notebooks.

Για να το χρησιμοποιήσεις χρειάζεσαι έναν λογαριασμό Google.

## Τι είναι ένα κελί;

Ένα notebook αποτελείται από **cells**.

Υπάρχουν κυρίως δύο τύποι:

### Code cell

Περιέχει Python:

```python
print("Hello")
```

### Text / Markdown cell

Περιέχει κείμενο, τίτλους, περιγραφές και σημειώσεις.

Έτσι μπορούμε να έχουμε στο ίδιο notebook:

- θεωρία,
- κώδικα,
- αποτελέσματα,
- επεξηγήσεις.

---

## Notebook ή Python script;

Στο GeoPython Skill Path θα χρησιμοποιήσουμε και τα δύο.

### Notebook

Ένα αρχείο notebook έχει συνήθως κατάληξη:

```text
.ipynb
```

Είναι κατάλληλο για:

- μάθηση,
- πειραματισμό,
- ανάλυση βήμα προς βήμα,
- παρουσίαση αποτελεσμάτων.

### Python script

Ένα Python script έχει κατάληξη:

```text
.py
```

Είναι κατάλληλο για:

- επαναλαμβανόμενες εργασίες,
- αυτοματοποίηση,
- επαναχρησιμοποίηση,
- workflows που θέλουμε να εκτελούμε πολλές φορές.

> 💡 **GeoTip**
>
> Notebook = μαθαίνω και δοκιμάζω
> Script = αυτοματοποιώ και επαναχρησιμοποιώ

## ⚠️ Συνηθισμένο λάθος

Αν γράψεις:

```python
print("Hello)
```

Γιατί;

Η σωστή μορφή είναι:

```python

```

## Mini άσκηση

Δημιούργησε ένα νέο code cell και εμφάνισε:

- το όνομά σου,
- μία πόλη,
- ένα υψόμετρο,
- ένα CRS.

Παράδειγμα:

```python
name = "Maria"
city = "Serres"
elevation = 120
crs = "EPSG:4326"

print(name)
print(city)
print(elevation)
print(crs)
```
