## Τι πρόβλημα λύνουμε

Ένα GIS workflow είναι γεμάτο τιμές με διαφορετικό ρόλο: όνομα layer, πλήθος features, longitude, elevation, CRS ή μια ένδειξη αν ένα σημείο είναι ενεργό. Αν η Python δεν ξέρει αν μια τιμή είναι αριθμός ή κείμενο, μπορεί είτε να δώσει error είτε να υπολογίσει κάτι διαφορετικό από αυτό που εννοείς.

## Γιατί είναι χρήσιμο

Πριν φιλτράρεις ένα dataset ή υπολογίσεις απόσταση, χρειάζεται να ξέρεις τι περιέχει κάθε μεταβλητή. Η διάκριση `float` από `str` είναι ιδιαίτερα σημαντική σε CSV αρχεία, όπου πολλές στήλες διαβάζονται αρχικά ως κείμενο.

## Βασικοί τύποι

```python
city = "Serres"      # str
population = 60000   # int
latitude = 41.09     # float
active = True        # bool
```

## `type()`

```python
print(type(city))
print(type(population))
print(type(latitude))
```

Η `type()` δεν αλλάζει τη μεταβλητή· επιστρέφει πληροφορία για το είδος της. Το `print()` απλώς εμφανίζει αυτή την πληροφορία. Αυτό είναι το πρώτο μικρό QA πριν χρησιμοποιήσεις μια τιμή σε γεωχωρικό υπολογισμό.

## Υπολογισμός εμβαδού

```python
width = 100
height = 50
area = width * height
print(area)
```

## Από m² σε ha

```python
area_m2 = 25000
area_ha = area_m2 / 10000
print(area_ha)
```

## Μετατροπή τύπου

```python
population = "60000"
population = int(population)
```

Η `int()` επιστρέφει νέο ακέραιο. Αν το κείμενο περιέχει μη αριθμητικούς χαρακτήρες, θα προκύψει `ValueError`. Σε πραγματικό workflow δεν μετατρέπουμε τυφλά: πρώτα βλέπουμε δείγμα τιμών και καταγράφουμε πόσες δεν μπορούν να μετατραπούν.

## ⚠️ Αριθμός ως κείμενο

```python
distance = "100"
print(distance + distance)
```

δίνει `100100`.

## Mini άσκηση

Δημιούργησε:
- `name = "Survey Point 01"`
- `x = 445250.50`
- `y = 4548120.75`
- `elevation = 82.4`
- `crs = "EPSG:2100"`
- `active = True`

και πρόσθεσε 1.5 m στο elevation.

### Μικρό QA

Έλεγξε ότι `x` και `y` είναι `float`, ότι το `elevation` παραμένει αριθμός και ότι το `crs` είναι κείμενο. Το αποτέλεσμα του elevation πρέπει να είναι `83.9`, ενώ το `active` πρέπει να παραμένει `True`. Αν δεις ένωση κειμένων αντί για πρόσθεση, έλεγξε πρώτα το `type()`.

## Τι κρατάμε

Μια μεταβλητή είναι όνομα που δείχνει σε τιμή. Ο τύπος της καθορίζει ποιες πράξεις έχουν νόημα. Στα GIS, τα ονόματα των μεταβλητών καλό είναι να δηλώνουν και μονάδες, όπως `area_m2` ή `distance_m`.
