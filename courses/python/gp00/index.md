# GP00 — Python από το μηδέν για Γεωπληροφορικούς

## Τι θα κάνουμε

Σε αυτή την ενότητα θα κάνουμε την πρώτη γνωριμία με την Python μέσα από παραδείγματα που έχουν νόημα για έναν φοιτητή ή επαγγελματία της Γεωπληροφορικής.

Δεν χρειάζεται προηγούμενη εμπειρία στον προγραμματισμό.

## Μαθησιακοί στόχοι

Μετά την ολοκλήρωση θα μπορείς να:

- χρησιμοποιείς το Google Colab,
- δημιουργείς μεταβλητές,
- δουλεύεις με λίστες και λεξικά,
- χρησιμοποιείς `if` και `for`,
- γράφεις απλές συναρτήσεις,
- χρησιμοποιείς βιβλιοθήκες,
- χρησιμοποιείς βασικά `pandas`,
- δημιουργείς το πρώτο σου `GeoDataFrame`,
- κάνεις βασικό GeoPython QA.
