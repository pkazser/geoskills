# 10. Readiness checkpoint

## Τι πρέπει να μπορείς να κάνεις

- Να δημιουργείς boolean μάσκα από μία ή πολλές στήλες.
- Να χρησιμοποιείς σωστά `&`, `|`, `~`, `isin()` και `between()`.
- Να χειρίζεσαι missing values με `isna`, `notna` και `na=False`.
- Να προσθέτεις απλό χωρικό περιορισμό και να ελέγχεις το CRS.
- Να κάνεις QA πριν από κάθε export.

## Τελική άσκηση

Πάρε το dataset και γράψε μία συνάρτηση που επιστρέφει ενεργά assets με score πάνω από όριο, λίστα τύπων και bbox. Επιστρέψε και report με rows και bounds.

Το GP06 απαντά “ποια features με ενδιαφέρουν;”. Στο GP07 θα μετρήσεις χαρακτηριστικά των επιλεγμένων geometries και στο GP08 θα χρησιμοποιήσεις απόσταση για να δημιουργήσεις νέες spatial zones.

## Μετάβαση

Στο GP07 θα χρησιμοποιήσεις κατάλληλο CRS για μήκη, εμβαδά και αποστάσεις.
