# 6. Missing values στο filtering

## Τι θα μάθεις

Θα αντιμετωπίζεις κενές τιμές χωρίς να τις θεωρείς αυτόματα false ή valid.

## Έλεγχος

## Τι πρόβλημα λύνουμε

Το missing δεν είναι κατηγορία και δεν πρέπει να αντιμετωπίζεται ως μηδέν ή ως “όχι”. Αποφάσισε αν το κρατάς για data-quality report ή αν το αποκλείεις από τη συγκεκριμένη ανάλυση και μέτρα τη διαφορά.

```python
missing = gdf[gdf["condition"].isna()]
complete = gdf[gdf["condition"].notna()]
```

Οι συγκρίσεις με `NaN` δεν συμπεριφέρονται σαν κανονική τιμή. Πρέπει να αποφασίσεις αν θα τις κρατήσεις για έλεγχο ποιότητας ή θα τις αποκλείσεις από ανάλυση.

## Πρακτική

Στο τρέχον dataset μέτρα `gdf.isna().sum()`. Παρότι δεν υπάρχουν missing values, γράψε φίλτρο που θα ήταν ασφαλές αν υπήρχαν. Αυτό κάνει το workflow ανθεκτικό σε επόμενο αρχείο.

## QA / λάθος

Μην χρησιμοποιείς `== None` για pandas columns. Χρησιμοποίησε `isna()`/`notna()` και κατέγραψε πόσα rows αποκλείστηκαν.

Το `NaN` δεν είναι κανονική τιμή και συνήθως δεν περνά μια σύγκριση ως `True`. Έλεγξε τα missing πριν το filter και αποφάσισε αν θα τα αποκλείσεις, θα τα κρατήσεις ως “unknown” ή θα τα χειριστείς με τεκμηριωμένο κανόνα. Μην θεωρήσεις ότι μηδενικό αποτέλεσμα σημαίνει πάντα απουσία features· μπορεί να είναι missing ή λάθος spelling.
