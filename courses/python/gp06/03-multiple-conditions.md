# 3. Πολλές συνθήκες

## Τι θα μάθεις

Θα εκφράζεις λογική τύπου AND, OR και NOT.

## Κώδικας

## Νοητικό μοντέλο

Κάθε συνθήκη είναι ξεχωριστή μάσκα. Το `&` κάνει τομή των masks, το `|` ένωση και το `~` άρνηση. Οι παρενθέσεις δεν είναι προαιρετικές επειδή η pandas εφαρμόζει vectorized operators.

```python
selected = gdf[
    (gdf["status"] == "active") &
    (gdf["score"] >= 75)
]
```

Οι παρενθέσεις είναι απαραίτητες. Το `&` σημαίνει “και”, το `|` “ή”, ενώ το `~` αντιστρέφει μια μάσκα.

## Εφαρμογή

Βρες ενεργά features με score 75–100 και κράτησε το subset. Έπειτα δοκίμασε `gdf[(gdf.status == "active") | (gdf.priority == "high")]` και σύγκρινε το πλήθος.

## QA / λάθη

Έλεγξε κάθε συνθήκη χωριστά και μετά το τελικό subset. Μην χρησιμοποιείς Python `and`/`or` ανάμεσα σε Series· χρησιμοποίησε `&`/`|`.

## Checkpoint

Πόσα rows θα επέστρεφε το φίλτρο αν ξεχνούσες τις παρενθέσεις; Το error είναι χρήσιμο σημάδι ότι πρέπει να διορθώσεις τη σύνταξη.

Το `&` σημαίνει AND, το `|` OR και το `~` NOT για Boolean Series. Οι παρενθέσεις είναι απαραίτητες: `(condition1) & (condition2)`. Χωρίς αυτές, η προτεραιότητα των τελεστών μπορεί να δώσει error ή διαφορετική λογική από αυτή που νομίζεις. Μετά από σύνθετο filter έλεγξε κάθε επιμέρους συνθήκη στο αποτέλεσμα.
