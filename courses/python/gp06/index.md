# GP06 — Filtering

Το GP06 δείχνει πώς μετατρέπεις ένα σύνολο υποδομών σε στοχευμένη επιλογή features. Η ροή είναι **Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**.

## Τι θα μάθεις

Θα γράφεις boolean συνθήκες, θα συνδυάζεις φίλτρα με `&`, `|`, `~`, θα χρησιμοποιείς `isin()`, αναζητήσεις κειμένου, αριθμητικά ranges, missing values και χωρικό περιορισμό με `.cx`. Το dataset `../../../downloads/python/data/gp06/assets.csv` περιέχει σημεία υποδομών με τύπο, κατάσταση, προτεραιότητα και score.
