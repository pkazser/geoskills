# 2. Boolean συνθήκες

## Τι θα μάθεις

Θα χρησιμοποιείς μια στήλη για να δημιουργείς μάσκα επιλογής.

## Έννοια

## Τι αλλάζει στα δεδομένα

Αλλάζει ο αριθμός rows, όχι οι geometry coordinates. Η predicate πρέπει να επιβεβαιωθεί με `min`, `max` ή `.all()`. Αν το `dtype` είναι λάθος, το φίλτρο μπορεί να αποτύχει πριν φτάσεις στο GIS μέρος.

Η έκφραση `gdf["score"] >= 80` επιστρέφει μία σειρά από `True` και `False`. Όταν τη βάζεις μέσα σε `gdf[...]`, κρατάς μόνο τις γραμμές με `True`.

```python
high_score = gdf[gdf["score"] >= 80]
```

Στο GP06 αυτό είναι φίλτρο ποιότητας. Οι αριθμητικές τιμές έχουν νόημα μόνο επειδή πρώτα επιβεβαίωσες ότι η στήλη είναι numeric.

## Πρακτική / QA

Εκτύπωσε `gdf["score"].dtype`, `high_score["score"].min()` και `len(high_score)`. Όλες οι τιμές του subset πρέπει να είναι τουλάχιστον 80.

## Συνηθισμένο λάθος

Μην γράφεις `gdf["score"] >= "80"`: συγκρίνεις αριθμούς με κείμενο. Αν η στήλη ήρθε ως string, καθάρισέ την πρώτα.

Η έκφραση `gdf["population"] > 1000` επιστρέφει Series από `True`/`False`, μία τιμή ανά row. Δεν είναι ακόμη το subset. Η σύνταξη `gdf[gdf["population"] > 1000]` χρησιμοποιεί τη Boolean mask για να κρατήσει τις rows όπου η τιμή είναι `True`. Αυτός ο διαχωρισμός βοηθά να ελέγξεις τη μάσκα πριν την εφαρμόσεις.
