# 4. CRS

## Τι θα μάθεις

Το CRS περιγράφει πώς ερμηνεύονται οι συντεταγμένες.

## Τι πρόβλημα λύνουμε

Οι αριθμοί longitude/latitude έχουν νόημα μόνο μαζί με το CRS τους. Δηλώνουμε EPSG:4326 επειδή οι τιμές είναι WGS84 σε μοίρες και μετασχηματίζουμε μόνο όταν το workflow χρειάζεται άλλο CRS.

```python
gdf.crs
```

Για longitude/latitude σε μοίρες χρησιμοποιούμε `EPSG:4326`.

Το `set_crs()` δηλώνει την ερμηνεία υπαρχουσών coordinates. Το `to_crs()` μετασχηματίζει geometry. Η διάκριση είναι κρίσιμη: το πρώτο δεν αλλάζει θέσεις, το δεύτερο αλλάζει αριθμητικές coordinates και μονάδες.

## Ορισμός και μετατροπή

```python
gdf = gdf.set_crs("EPSG:4326")
```

Το `set_crs()` δηλώνει τι CRS έχουν ήδη οι τιμές. Δεν μετακινεί τα σημεία. Το `to_crs()` μετατρέπει τις συντεταγμένες σε άλλο σύστημα.

## QA

```python
assert gdf.crs is not None
assert gdf.crs.to_string() == "EPSG:4326"
```

## GeoTip

Δεν χρησιμοποιούμε `to_crs()` για να διορθώσουμε άγνωστο CRS. Πρώτα πρέπει να γνωρίζουμε το αρχικό CRS.

## Γιατί είναι χρήσιμο

Δύο ίδια ζεύγη αριθμών μπορούν να σημαίνουν διαφορετικές θέσεις αν ερμηνευτούν σε διαφορετικό CRS. Λάθος CRS επηρεάζει overlay, distance, area και τη θέση στον χάρτη.

## Πρακτική εκτέλεση

```python
print(gdf.crs)
projected = gdf.to_crs("EPSG:2100")
print(projected.crs)
```

Το `projected` έχει μετασχηματισμένες συντεταγμένες. Το αρχικό `gdf` παραμένει σε EPSG:4326. Για απλή εμφάνιση σημείων κρατάμε το αρχικό CRS· για μετρήσεις επιλέγουμε κατάλληλο projected CRS.

## QA check

```python
assert gdf.crs.to_epsg() == 4326
```

Το `set_crs("EPSG:4326")` θα ήταν σωστό μόνο αν οι υπάρχουσες coordinates είναι ήδη longitude/latitude. Δεν αλλάζει τις τιμές. Το `to_crs("EPSG:2100")` χρειάζεται γνωστό source CRS και αλλάζει τις coordinates. Αν δηλώσεις λάθος source CRS, κάθε επόμενος μετασχηματισμός θα είναι συνεπής αλλά χωρικά λανθασμένος.
