# 1. Mission — από το ερώτημα στο workflow

## Τι θα μάθεις

Θα μετατρέψεις ένα γενικό GIS ερώτημα σε συγκεκριμένα inputs, outputs και ελέγχους.

## Γιατί είναι χρήσιμο

Ένα project δεν ξεκινά με `read_file()`. Ξεκινά με απόφαση: τι θέλουμε να μετρήσουμε, σε ποια περιοχή, με ποια δεδομένα και με ποιον περιορισμό. Αυτό αποτρέπει χάρτες που φαίνονται σωστοί αλλά απαντούν λάθος ερώτημα.

## Η έννοια

Στο capstone χρησιμοποιούμε τέσσερις πηγές: study area ως mask, administrative zones ως μονάδες αναφοράς, services ως σημεία και roads ως βοηθητικό context. Η “κάλυψη” θα είναι η περιοχή που βρίσκεται μέσα σε buffer γύρω από ενεργές βασικές υπηρεσίες· δεν είναι ισοδύναμη με πραγματική προσβασιμότητα.

```python
from pathlib import Path

root = Path("data/core-capstone")
paths = {
    "study": root / "study_area.gpkg",
    "zones": root / "administrative_zones.gpkg",
    "services": root / "services.csv",
    "roads": root / "roads.gpkg",
}
```

Το `Path` κρατά τα paths συγκεντρωμένα και μειώνει τα λάθη όταν το notebook μετακινηθεί από τον υπολογιστή στο Colab.

## Εφαρμογή στο dataset

Πριν φορτώσεις δεδομένα, γράψε σε μία πρόταση την απόφαση: “Θα ελέγξω τις ενεργές υπηρεσίες, θα τις αντιστοιχίσω σε ζώνες και θα εκτιμήσω κάλυψη με buffer 500 m σε projected CRS”. Κατέγραψε επίσης τι δεν κάνεις: routing, πληθυσμιακή στάθμιση ή αξιολόγηση ποιότητας υπηρεσίας.
