# GeoPython Core

## Κατάσταση

Η διαδρομή GeoPython Core (GP00–GP10 και Core Capstone) έχει μεταφερθεί στο GeoSkills και διατίθεται ως **πιλοτική έκδοση υπό αξιολόγηση**. Το υλικό διατηρεί τη μαθησιακή αλληλουχία και τις πρακτικές ασκήσεις του source repository. Οι πρακτικές εκτελέσεις των notebooks αξιολογούνται ακόμη συγκεντρωτικά.

## Τι θα μάθεις

Θα ξεκινήσεις από τις βασικές έννοιες της Python και θα περάσεις σταδιακά σε pandas, GeoPandas, GeoPackage, CRS, καθαρισμό δεδομένων, μετρήσεις, buffers, spatial joins και overlay. Το Core Capstone συνδυάζει τον κύκλο **Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**.

## Προαπαιτούμενα και τρόπος εργασίας

Δεν απαιτείται προηγούμενη εμπειρία Python. Χρειάζεσαι βασική άνεση με αρχεία και φακέλους, προαιρετικά έναν λογαριασμό Google για Colab και διάθεση να συμπληρώνεις τα starter notebooks. Η εξάσκηση μπορεί να γίνει στο Google Colab ή σε τοπικό Python περιβάλλον με τα πακέτα που αναφέρονται σε κάθε notebook.

### Πώς θα αποκτήσεις τα αρχεία

**Google Colab.** Άνοιξε το starter notebook από τον σύνδεσμο Colab στη σελίδα του αντίστοιχου μαθήματος. Το Colab δημιουργεί δικό σου αντίγραφο· εκτέλεσε τα κελιά με τη σειρά και κράτησε τις απαντήσεις σου εκεί ή σε ξεχωριστό αντίγραφο.

**Τοπική εργασία.** Κατέβασε το starter notebook και τα δεδομένα από τους πραγματικούς συνδέσμους κάθε μαθήματος. Οι σελίδες GP00–GP10 περιλαμβάνουν ξεχωριστές λήψεις για notebook και dataset· δεν χρειάζεται να χρησιμοποιήσεις διαδρομή φακέλου ως σύνδεσμο.

**Συγκεντρωτικό πακέτο.** Κατέβασε το {download}`GeoPython Core GP00–GP10 — starter notebooks και δεδομένα <../../downloads/python/GeoPython_Core_GP00-GP10_v1.0.zip>`. Το πακέτο περιλαμβάνει μόνο τα starter notebooks των GP00–GP10 και τα δεδομένα GP01–GP10. Δεν περιλαμβάνει solution notebooks ή τα δεδομένα του Core Capstone.

**Άδειες και προέλευση.** Η τεκμηρίωση των datasets βρίσκεται στο {download}`DATA_PROVENANCE.md <../../downloads/python/DATA_PROVENANCE.md>`. Η άδεια CC BY 4.0 αφορά μόνο τα συγκεκριμένα datasets GP01–GP10.

## Πρακτική συμβουλή

Μην προχωράς μόνο με αντιγραφή κώδικα. Σε κάθε checkpoint κατέγραψε τι άλλαξε, πόσες εγγραφές έχεις, ποιο είναι το CRS, ποια είναι τα όρια και πώς επαλήθευσες το αποτέλεσμα. Τα datasets είναι εκπαιδευτικά· η προέλευση και η άδεια κάθε συνόλου πρέπει να επιβεβαιωθούν πριν από δημόσια αναδιανομή.
