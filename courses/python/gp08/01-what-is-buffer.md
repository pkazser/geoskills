# 1. Τι είναι buffer

## Τι θα μάθεις

Θα καταλάβεις τι γεωχωρικό ερώτημα απαντά ένα buffer.

## Γιατί είναι χρήσιμο

Το “τι βρίσκεται σε απόσταση έως 500 m από μια υπηρεσία;” είναι συνηθισμένο ερώτημα σε προσβασιμότητα, πολιτική προστασία και σχεδιασμό υποδομών.

## Η έννοια

## Νοητικό μοντέλο

Input είναι μία geometry και απόσταση, output νέα geometry. Τα attributes δεν απαντούν από μόνα τους το ερώτημα εγγύτητας· το buffer δημιουργεί την περιοχή μέσα στην οποία θα ψάξουμε.

Buffer είναι νέα γεωμετρία που περιβάλλει ένα feature σε συγκεκριμένη απόσταση. Ένα point δίνει κυκλικό polygon, μια line δίνει ζώνη γύρω από τη διαδρομή και ένα polygon μεγαλώνει προς όλες τις πλευρές.

```python
school_buffer = point.geometry.buffer(500)
```

Το `500` δεν είναι από μόνο του “500 μέτρα”. Η μονάδα προέρχεται από το CRS.

## Εφαρμογή και QA

Διάβασε `services.csv`, δημιούργησε points και έλεγξε πέντε rows, `Point` geometry και EPSG:4326 πριν κάνεις μετασχηματισμό. Το αποτέλεσμα του buffer πρέπει να γίνει `Polygon`.

## Πρόσεξε

Μην ξεκινάς buffer πριν ελέγξεις CRS και units. Ένα τεχνικά επιτυχές buffer μπορεί να είναι γεωγραφικά λάθος.

Ένα buffer απαντά “ποια περιοχή βρίσκεται έως μια συγκεκριμένη απόσταση από το feature;”. Γύρω από σχολείο μπορεί να είναι ζώνη 500 m, γύρω από ποτάμι ζώνη εκατέρωθεν της γραμμής ή γύρω από προστατευόμενη περιοχή ζώνη διαχείρισης. Το αποτέλεσμα είναι νέα polygon geometry, όχι απλώς numeric distance field.
