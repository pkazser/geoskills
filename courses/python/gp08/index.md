# GP08 — Buffer Analysis

Στο GP08 μαθαίνεις να απαντάς ερωτήματα απόστασης: ποια σχολεία εξυπηρετούνται σε ακτίνα 500 m, ποιοι δρόμοι επηρεάζουν μια περιοχή και πού επικαλύπτονται ζώνες επιρροής. Η ροή είναι **Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**.

## Τι θα μάθεις

Θα δημιουργείς buffers γύρω από points, lines και polygons, θα επιλέγεις features μέσα σε buffer, θα ελέγχεις overlap και θα κάνεις export. Το dataset `../../../downloads/python/data/gp08/` περιέχει υπηρεσίες, δρόμους και περιοχή μελέτης γύρω από τις Σέρρες. Οι μετρήσεις γίνονται σε EPSG:2100.
