# GP08 — Ζώνες επιρροής και buffer analysis

> Κατάσταση: πιλοτική έκδοση v2.0.

Στο GP08 μαθαίνεις να μετατρέπεις ένα ερώτημα εγγύτητας σε ελεγχόμενο γεωχωρικό workflow. Θα δημιουργήσεις ζώνες γύρω από σχολεία και δρόμους, θα συγκρίνεις αποστάσεις, θα επιλέξεις υπηρεσίες μέσα σε ζώνες και θα τεκμηριώσεις τι σημαίνει πραγματικά το αποτέλεσμα. Η ροή είναι **Πρόβλεψε → Εκτέλεσε → Έλεγξε → Ερμήνευσε**.

## Τι θα μάθεις

Θα δημιουργείς buffers γύρω από σημεία, γραμμές και polygons, θα επιλέγεις features μέσα σε ζώνη, θα ελέγχεις overlap και θα κάνεις round-trip export. Το dataset `../../../downloads/python/data/gp08/` περιέχει πέντε υπηρεσίες, δύο δρόμους και μία περιοχή μελέτης γύρω από τις Σέρρες. Οι μετρήσεις γίνονται σε EPSG:2100 μετά από μετασχηματισμό από EPSG:4326.

## Πώς θα εργαστείς

Το notebook έχει ένα πλήρες καθοδηγούμενο παράδειγμα 500 m και στη συνέχεια κελιά στα οποία αλλάζεις την ακτίνα, συγκρίνεις αποτελέσματα και διατυπώνεις δικό σου ερώτημα. Δεν δημοσιεύεται solution notebook. Οι ζώνες είναι μοντέλο ευθύγραμμης/επίπεδης εγγύτητας στο EPSG:2100· δεν υπολογίζουν χρόνο μετακίνησης ή οδική προσβασιμότητα.

## Mini Challenge και readiness checkpoint

Διάλεξε ένα διαφορετικό συγγενές ερώτημα με τα ίδια δεδομένα, αιτιολόγησε την ακτίνα και τη χωρική πράξη, έλεγξε CRS/μονάδες/γεωμετρίες/counts και κατέγραψε περιορισμούς. Στο καθοδηγούμενο παράδειγμα οι οδικοί buffers χρησιμοποιούν ακτίνα 500 m· τα 250 m παραμένουν διαθέσιμα ως ελεγχόμενη σύγκριση όπου αυτό βοηθά την ερμηνεία. Είσαι έτοιμος όταν μπορείς να εξηγήσεις γιατί ένα buffer 500 m δεν αποδεικνύει πρόσβαση σε πέντε λεπτά και να ελέγξεις ένα εξαγόμενο GeoPackage μετά την επαναφόρτωσή του.
