# 2. Buffer γύρω από σημεία

## Τι θα μάθεις

Θα δημιουργήσεις ζώνη επιρροής γύρω από points και θα τη συνδέσεις με πρακτικό ερώτημα.

## Παράδειγμα

## Τι αλλάζει

Το αρχικό Point αντικαθίσταται στο αντίγραφο από Polygon, ενώ το `service_id` μένει για ιχνηλασιμότητα. Γι’ αυτό κρατάμε χωριστά το source και το αποτέλεσμα.

```python
schools = services_m[services_m["service_type"].eq("school")].copy()
schools["geometry"] = schools.geometry.buffer(500)
```

Κρατάμε αντίγραφο για να μην αντικαταστήσουμε τις αρχικές point geometries. Μετά το buffer κάθε σχολείο γίνεται polygon.

## Εφαρμογή στο dataset

Το dataset έχει δύο σχολεία. Δημιούργησε buffers 500 m και σύγκρινε τα bounds τους με τα bounds των αρχικών points. Οι αριθμοί πρέπει να είναι σε κλίμακα μέτρων επειδή χρησιμοποιείς EPSG:2100.

## Αναμενόμενο αποτέλεσμα / QA

Περίμενε δύο polygons, ίδιο πλήθος features και μη κενές geometries. Έλεγξε `geom_type`, CRS και ότι κάθε buffer έχει θετικό εμβαδόν.

## GeoTip

Η προεπιλεγμένη κυκλικότητα είναι αρκετή για αρχικό workflow. Σε τεχνική ανάλυση μπορεί να ρυθμίσεις `resolution`, αλλά πρώτα έλεγξε τη λογική της απόστασης.

Σε Point buffer, το distance είναι ακτίνα. `buffer(500)` σημαίνει ζώνη περίπου κυκλικής μορφής με ακτίνα 500 m όταν το CRS έχει metre units, όχι διάμετρο 500 m. Η νέα geometry έχει συνήθως τύπο Polygon και τα αρχικά attributes μπορούν να διατηρηθούν στο αντίγραφο.

## Επόμενο βήμα

Θα δεις ότι το ίδιο εργαλείο δουλεύει και σε lines ή polygons.
