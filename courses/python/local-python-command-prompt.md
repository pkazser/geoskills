# Από το Colab στο Command Prompt — η πρώτη μου τοπική εκτέλεση Python

**Χρόνος:** περίπου 20–30 λεπτά

**Προαπαιτούμενα:** βασική άνεση με αρχεία και φακέλους· δεν απαιτούνται GIS βιβλιοθήκες.

## Στόχος

Θα εκτελέσεις ένα μικρό Python script από το Windows Command Prompt (CMD), θα διακρίνεις script, interpreter και notebook και θα παραδώσεις ένα `.py` αρχείο μαζί με τεκμηριωμένο αποτέλεσμα. Το Colab παραμένει η βασική διαδρομή των notebooks· αυτός ο οδηγός είναι συμπληρωματικός.

## 1. Script, interpreter και notebook

Ένα `.py` είναι αρχείο script που εκτελείται από την Python. Ο **interpreter** είναι το πρόγραμμα Python που διαβάζει και εκτελεί το script. Ένα `.ipynb` είναι notebook με κελιά κώδικα και Markdown, όπως αυτά που χρησιμοποιείς στο Colab. Το CMD είναι το παράθυρο όπου πληκτρολογείς εντολές των Windows· δεν είναι το ίδιο με το prompt της Python `>>>`.

Ένα script είναι χρήσιμο όταν θέλεις να επαναλάβεις μια μικρή διαδικασία με την ίδια σειρά εντολών ή να τη μοιραστείς ως αρχείο.

## 2. Έλεγξε αν υπάρχει Python

Άνοιξε **Command Prompt** από το μενού Έναρξη και εκτέλεσε:

```bat
py --version
```

Αν εμφανιστεί ότι το `py` δεν αναγνωρίζεται, δοκίμασε:

```bat
python --version
```

Αν αποτύχουν και οι δύο εντολές, σταμάτησε εδώ. Χρησιμοποίησε την επίσημη σελίδα εγκατάστασης της Python για Windows ή ζήτησε βοήθεια από τον υπεύθυνο του συστήματος· μην εκτελέσεις τυχαίες εντολές και μην χρειαστείς δικαιώματα διαχειριστή για αυτό το μάθημα.

## 3. Φάκελος εργασίας

Στο ίδιο παράθυρο CMD εκτέλεσε:

```bat
mkdir "%USERPROFILE%\Documents\GeoPython"
cd /d "%USERPROFILE%\Documents\GeoPython"
dir
```

Το `mkdir` δημιουργεί φάκελο, το `cd /d` μετακινεί και σε διαφορετικό drive αν χρειάζεται, ενώ το `dir` εμφανίζει τα περιεχόμενα. Οι εντολές αυτές είναι CMD εντολές, όχι Python statements.

## 4. Δημιούργησε και εκτέλεσε το πρώτο script

Δημιούργησε ένα αρχείο με όνομα `hello.py` σε αυτόν τον φάκελο, χρησιμοποιώντας έναν απλό editor. Πληκτρολόγησε:

```python
print('Hello GeoPython!')
```

Στο Save As επίλεξε **All files** και κωδικοποίηση UTF-8, ώστε το αρχείο να μην αποθηκευτεί ως `hello.py.txt`. Έλεγξε με `dir` ότι το όνομα τελειώνει πραγματικά σε `.py`.

Εκτέλεσε μία από τις παρακάτω εντολές, ανάλογα με αυτή που αναγνώρισε το σύστημά σου:

```bat
py hello.py
```

ή:

```bat
python hello.py
```

Αναμενόμενο αποτέλεσμα: εμφανίζεται η φράση `Hello GeoPython!`.

## 5. Ο interactive interpreter

Από τον ίδιο φάκελο εκτέλεσε `py` ή `python` χωρίς όνομα αρχείου. Θα δεις το prompt `>>>`. Εκεί γράφεις Python statements, για παράδειγμα `2 + 2`. Για έξοδο γράψε:

```python
exit()
```

Μην πληκτρολογήσεις `exit()` ως εντολή CMD και μην πληκτρολογήσεις `mkdir` μέσα στο `>>>`.

## 6. Προαιρετικό απομονωμένο περιβάλλον

Αν θέλεις να κρατήσεις ξεχωριστές ρυθμίσεις για ένα project, μπορείς να δημιουργήσεις ένα `venv` χωρίς activation:

```bat
py -m venv .venv
```

Αν το `py` δεν είναι διαθέσιμο, χρησιμοποίησε `python -m venv .venv`. Στη συνέχεια εκτέλεσε απευθείας την Python του περιβάλλοντος:

```bat
.venv\Scripts\python.exe hello.py
```

Η μορφή `python -m pip` σημαίνει ότι ζητάς από τον συγκεκριμένο interpreter να εκτελέσει το module `pip`. Μην εγκαταστήσεις GeoPandas ή QGIS για αυτή την εισαγωγική άσκηση και μην εγκαθιστάς πακέτα σε base/global environment.

## 7. Μικρή δραστηριότητα με την standard library

Δημιούργησε ένα αρχείο `sites.csv` στον φάκελο εργασίας με περιεχόμενο:

```text
name,category
Athens,city
Serres,city
```

Δημιούργησε `read_sites.py` με τον παρακάτω σκελετό και συμπλήρωσε τα TODOs:

```python
import csv
from pathlib import Path

data_path = Path("sites.csv")

if not data_path.exists():
    raise FileNotFoundError(f"Δεν βρέθηκε: {data_path}")

with data_path.open(newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    rows = list(reader)

# TODO: εμφάνισε το πλήθος των γραμμών και τα ονόματα των sites.
```

Το `csv` και το `pathlib` ανήκουν στη standard library: δεν χρειάζονται εξωτερική εγκατάσταση. Έλεγξε ότι το `sites.csv` βρίσκεται στον ίδιο φάκελο όπου εκτελείς το script και ότι το πλήθος των γραμμών είναι 2.

## 8. Συνηθισμένα σφάλματα

- **`'py' is not recognized` ή `'python' is not recognized`:** δεν είναι διαθέσιμη η εντολή στο PATH. Σταμάτησε και ακολούθησε ασφαλή οδηγία εγκατάστασης.
- **`ModuleNotFoundError`:** το script ζητά module που δεν υπάρχει στο επιλεγμένο περιβάλλον. Μην εγκαταστήσεις τυχαία πακέτα· έλεγξε πρώτα ποιον interpreter χρησιμοποιείς.
- **`FileNotFoundError`:** έλεγξε το όνομα του αρχείου και το working directory με `cd` και `dir`.
- **Λάθος working directory:** το CMD και η Python μπορεί να κοιτούν διαφορετικό φάκελο από αυτόν που νομίζεις. Εκτέλεσε `cd` και έλεγξε με `dir`.
