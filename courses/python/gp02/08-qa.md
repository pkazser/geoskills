## Τι θα μάθεις

Θα μετατρέψεις τους ελέγχους ποιότητας σε κώδικα που μπορεί να εκτελείται κάθε φορά.

```python
assert len(gdf) > 0
assert gdf.crs is not None
assert gdf.crs.to_string() == "EPSG:4326"
assert gdf.geometry.geom_type.eq("Point").all()
assert gdf.geometry.notna().all()
assert not gdf.geometry.is_empty.any()
assert gdf.geometry.is_valid.all()
essential = ["observation_id", "longitude", "latitude"]
assert gdf[essential].notna().all().all()
assert gdf["observation_id"].is_unique
assert gdf["longitude"].between(-180, 180).all()
assert gdf["latitude"].between(-90, 90).all()
assert gdf.geometry.x.eq(gdf["longitude"]).all()
assert gdf.geometry.y.eq(gdf["latitude"]).all()
```

Τα απαραίτητα πεδία (`observation_id`, `longitude`, `latitude`) πρέπει να είναι
πλήρη. Τα προαιρετικά `category`, `elevation_m` και `status` ελέγχονται χωριστά
και δεν απορρίπτουν αυτόματα το τελικό αποτέλεσμα: στο παρόν dataset το `O07`
διατηρεί κενά `category` και `elevation_m`.

## Οπτικός έλεγχος

```python
gdf.plot(figsize=(7, 6), color="darkgreen")
```

Τα σημεία πρέπει να βρίσκονται στην ίδια περιοχή. Ένας ακραίος οπτικός outlier είναι λόγος για επανέλεγχο.

## Τι αποδεικνύει κάθε check

Το CRS και οι geometry types ελέγχουν τη δομή, τα missing και τα unique IDs την πληρότητα, τα coordinate ranges τη βασική γεωγραφική λογική και τα bounds την αναμενόμενη περιοχή. Η σύγκριση `geometry.x/y` με τις στήλες ελέγχει τη σωστή σειρά X/Y στο συγκεκριμένο μη μετασχηματισμένο workflow. Κανένα check μόνο του δεν αρκεί. Ένα layer μπορεί να έχει valid Points σε λάθος χώρα.

### Πρακτικό report

Κράτησε rows πριν/μετά, πλήθος missing που έμειναν, πλήθος invalid και bounds. Αν ένα check είναι ειδικό μόνο για το dataset, σημείωσέ το ως τέτοιο αντί να το παρουσιάσεις ως γενικό κανόνα.

## Γιατί είναι χρήσιμο

Τα `assert` μετατρέπουν την κρίση του αναλυτή σε ελέγξιμο κανόνα. Αν μια νέα έκδοση του CSV έχει πρόβλημα, το workflow σταματά πριν παραχθεί λάθος output.

## Αναμενόμενο αποτέλεσμα

Μετά τον καθαρισμό πρέπει να έχεις μοναδικά IDs, αριθμητικές συντεταγμένες, μόνο Points, CRS `EPSG:4326`, μη κενές και valid geometries. Ο χάρτης πρέπει να δείχνει ένα συνεκτικό σύνολο σημείων.

## Checkpoint

Πρόσθεσε ένα check που να αποτυγχάνει αν το καθαρό dataset είναι κενό. Ο
κανόνας `len(gdf) >= 5` είναι acceptance check μόνο για το συγκεκριμένο
συνθετικό dataset, όχι καθολικό κριτήριο ποιότητας. Το `len(gdf)` δείχνει αν
χάθηκαν ή προστέθηκαν features, το CRS αν οι coordinates έχουν γνωστή αναφορά
και το `is_valid` αν η geometry είναι τεχνικά έγκυρη· κανένα από αυτά δεν
αποδεικνύει μόνο του ότι το σημείο βρίσκεται στη σωστή περιοχή.
