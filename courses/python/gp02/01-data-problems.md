# 1. Γιατί χρειάζεται καθαρισμός

## Τι θα μάθεις

Ένα αρχείο μπορεί να ανοίγει κανονικά και παρ’ όλα αυτά να περιέχει λάθη. Ο καθαρισμός είναι μέρος της ανάλυσης, όχι ξεχωριστή πολυτέλεια.

## Τα προβλήματα του dataset

Στο συνθετικό `observations_dirty.csv` θα συναντήσεις:

- κενή κατηγορία,
- αριθμούς αποθηκευμένους ως κείμενο,
- διπλότυπο `observation_id`,
- συντεταγμένη εκτός ορίων,
- κενό latitude,
- σημείο που πρέπει να ελεγχθεί πριν χρησιμοποιηθεί.

## Η σωστή σειρά

```text
Φορτώνω → Μετρώ → Καταλαβαίνω → Διορθώνω → Ελέγχω
```

Δεν ξεκινάμε με `dropna()` χωρίς να ξέρουμε τι χάνουμε. Κάθε κανόνας καθαρισμού πρέπει να μπορεί να εξηγηθεί.

## Checkpoint

Πριν αλλάξεις δεδομένα, γράψε ποιο πρόβλημα βλέπεις σε κάθε στήλη.

## Γιατί είναι χρήσιμο σε πραγματικό workflow

Ένα GIS layer μπορεί να εμφανίζεται στον χάρτη και παρ’ όλα αυτά να δίνει λάθος αποτέλεσμα σε φίλτρα, μετρήσεις ή spatial analysis. Ο καθαρισμός μειώνει αυτόν τον κίνδυνο πριν δημιουργήσουμε geometry ή εξάγουμε αρχείο.

## Πρακτική εκτέλεση στο dataset

Τρέξε πρώτα το κελί προετοιμασίας του starter notebook, ώστε να υπάρχει το
`DATA_ROOT`. Δεν χρησιμοποιούμε μη φορητό σχετικό path μέσα στο μάθημα.

```python
import pandas as pd

df = pd.read_csv(DATA_ROOT / "gp02" / "observations_dirty.csv")
print(df.shape)
print(df.dtypes)
print(df.isna().sum())
```

Θα δεις ότι το `O04` επαναλαμβάνεται, το `O05` έχει longitude `999`, το `O06` δεν έχει latitude και το `O07` έχει μη αριθμητικό elevation. Αυτές οι παρατηρήσεις είναι το υλικό του μαθήματος.

## QA check και checkpoint

```python
assert len(df) == 10
assert df["observation_id"].duplicated().sum() == 1
```

Πριν διορθώσεις κάτι, σημείωσε τα προβλήματα και τον κανόνα που θα χρησιμοποιήσεις. Η σωστή λογική είναι: εντοπίζω → κατανοώ → αποφασίζω → τεκμηριώνω → ελέγχω ξανά. Μικρό checkpoint: γράψε για τις `O04`, `O05`, `O06` και `O07` αν κάθε πεδίο είναι essential ή optional και τι θα συνέβαινε αν κρατούσες τη γραμμή. Η αναγκαιότητα ενός πεδίου εξαρτάται από τον σκοπό της εργασίας. Η κενή `category` της `O07` είναι διαφορετική από μια κενή latitude, ενώ το `not_available` είναι μη αριθμητική ένδειξη και όχι έγκυρο elevation.
