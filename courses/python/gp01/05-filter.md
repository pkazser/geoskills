# 5. Filter — Επιλογή εγγραφών

## Τι θα μάθεις

Θα κρατήσεις μόνο τα σημεία που ικανοποιούν μια σαφή συνθήκη.

## Τι πρόβλημα λύνουμε

Η ανάλυση χρειάζεται συγκεκριμένο subset, όχι όλο τον πίνακα. Το ερώτημα εδώ είναι “ποια σημεία είναι checked και έχουν elevation πάνω από 70 m;”.

```python
selected = gdf[
    (gdf["elevation_m"] > 70) &
    (gdf["status"] == "checked")
].copy()
```

Στην pandas χρησιμοποιούμε `&` για το «και» και βάζουμε κάθε συνθήκη σε παρένθεση.

Η μάσκα επιστρέφει `True` ή `False` για κάθε row. Το `.copy()` δημιουργεί ανεξάρτητο subset και αποφεύγει ασαφείς αναθέσεις όταν προσθέσουμε νέα στήλη αργότερα.

## Έλεγχος αποτελέσματος

```python
print("Αρχικές γραμμές:", len(gdf))
print("Επιλεγμένες γραμμές:", len(selected))
selected[["name", "category", "elevation_m", "status"]]
```

Πάντα συγκρίνουμε το πλήθος πριν και μετά το φίλτρο. Ένα φίλτρο που επιστρέφει μηδέν γραμμές μπορεί να σημαίνει λάθος συνθήκη.

Ερμήνευσε το πλήθος μαζί με τα values: κάθε επιλεγμένο feature πρέπει να είναι `checked` και πάνω από 70. Αν το πλήθος είναι μηδέν, έλεγξε πρώτα spelling, τύπο `elevation_m` και αν χρησιμοποιήθηκαν παρενθέσεις.

## Mini άσκηση

Δημιούργησε ένα νέο `urban_points` που να περιέχει μόνο την κατηγορία `urban`.

Μετά το filter κάνε `urban_points["category"].unique()` και σύγκρινε `len(urban_points)` με `len(gdf)`. Αυτό είναι μικρό αλλά ουσιαστικό QA.

## Γιατί ελέγχουμε και το νόημα;

Ένα φίλτρο μπορεί να είναι συντακτικά σωστό και επιχειρησιακά λάθος. Για παράδειγμα, το `status == "Checked"` επιστρέφει μηδέν αν τα πραγματικά values είναι lowercase. Γι’ αυτό διαβάζουμε πρώτα `value_counts()` και μετά επιβεβαιώνουμε ότι κάθε selected row ικανοποιεί όλες τις συνθήκες. Το πλήθος είναι ένδειξη· οι τιμές είναι η ερμηνεία.
