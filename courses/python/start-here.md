# Ξεκίνα από εδώ

Καλώς ήρθες στο **GeoPython Skill Path**.

Το υλικό αυτό απευθύνεται σε φοιτητές και επαγγελματίες της Γεωπληροφορικής που θέλουν να χρησιμοποιήσουν την Python σε πραγματικά GIS προβλήματα, χωρίς να χρειάζεται να γίνουν πρώτα προγραμματιστές.

## Τι θα μάθεις

Κατά τη διάρκεια του GeoPython Skill Path θα μάθεις να:

- διαβάζεις γεωχωρικά δεδομένα με Python,
- ελέγχεις CRS, γεωμετρίες και γνωρίσματα,
- καθαρίζεις προβληματικά δεδομένα,
- κάνεις χωρικά φίλτρα και μετρήσεις,
- χρησιμοποιείς buffer, spatial join και overlay,
- αυτοματοποιείς επαναλαμβανόμενες GIS εργασίες,
- ελέγχεις αν ένα αποτέλεσμα είναι πραγματικά σωστό,
- οργανώνεις τον κώδικα και τα δεδομένα σου με Git και GitHub.

## Πώς δουλεύουμε

Δεν ξεκινάμε από μεγάλη θεωρία προγραμματισμού.

Ξεκινάμε από ένα πραγματικό γεωχωρικό πρόβλημα και μαθαίνουμε την Python που χρειάζεται για να το λύσουμε.

Η βασική ροή είναι:

**Κατανοώ → Ελέγχω → Επεξεργάζομαι → Επαληθεύω → Εξάγω**

## Τι χρειάζεσαι

Για τις πρώτες ενότητες χρειάζεσαι μόνο:

- έναν σύγχρονο browser,
- λογαριασμό Google,
- πρόσβαση στο Google Colab.

Αργότερα θα χρησιμοποιήσουμε επίσης:

- Python τοπικά,
- Visual Studio Code,
- QGIS,
- Git,
- GitHub.

## Colab ή τοπική Python;

Στην αρχή χρησιμοποιούμε κυρίως **Google Colab**, ώστε να μην ασχοληθούμε με εγκαταστάσεις και ρυθμίσεις.

Όταν αρχίσουμε να δημιουργούμε επαναχρησιμοποιήσιμα workflows και αυτοματισμούς, θα περάσουμε σταδιακά και σε τοπική Python.

## Πώς είναι οργανωμένη κάθε ενότητα

Κάθε ενότητα περιλαμβάνει:

1. το πρόβλημα που θα λύσουμε,
2. τα δεδομένα,
3. τις βασικές έννοιες,
4. καθοδηγούμενο workflow,
5. checkpoints,
6. συνηθισμένα λάθη,
7. mini challenge,
8. λύση,
9. έλεγχο αποτελεσμάτων,
10. σύντομη ανακεφαλαίωση.

## Πολύ σημαντικό: ο κώδικας που τρέχει δεν είναι πάντα σωστός

Στη Γεωπληροφορική ένα πρόγραμμα μπορεί να εκτελεστεί χωρίς error και παρ’ όλα αυτά το αποτέλεσμα να είναι λανθασμένο.

Γι’ αυτό ελέγχουμε πάντα:

- CRS,
- μονάδες μέτρησης,
- αριθμό εγγραφών,
- geometry types,
- missing values,
- εύρος τιμών,
- χωρική λογική,
- αποτέλεσμα στον χάρτη.

## Η Τεχνητή Νοημοσύνη ως βοηθός

Μπορείς να χρησιμοποιείς εργαλεία ΤΝ για να σε βοηθούν με τον κώδικα.

Η σωστή διαδικασία όμως είναι:

**Ρωτάω → Κατανοώ → Εκτελώ → Ελέγχω → Διορθώνω**

Δεν αντιγράφουμε απλώς κώδικα χωρίς να καταλαβαίνουμε τι κάνει.
