# 7. Σκέψου σαν αναλυτής GIS — σενάριο και αυτοαξιολόγηση

## Μικρή αποστολή: Πού θα τοποθετούσες έναν νέο χώρο πρασίνου;

Ένας δήμος θέλει να εξετάσει ποιες περιοχές έχουν περιορισμένη πρόσβαση σε χώρους πρασίνου. Δεν σου ζητά ακόμη να σχεδιάσεις έναν χάρτη· σου ζητά να περιγράψεις πώς θα οργανώσεις την εργασία.

**Α. Τι ακριβώς θα μετρήσεις;** Γράψε μια πρόταση που να διευκρινίζει τι σημαίνει «πρόσβαση»: ευθεία απόσταση, διαδρομή με τα πόδια ή χρόνος; Το αποτέλεσμα εξαρτάται από αυτόν τον ορισμό.

**Β. Ποια δεδομένα χρειάζεσαι;** Σκέψου πολύγωνα πάρκων, σημεία εισόδων, πεζοδρομημένους δρόμους ή δίκτυο πεζών, πληθυσμιακά στοιχεία ανά μικρή περιοχή και ενδεχομένως εμπόδια/διαβάσεις.

**Γ. Ποιους ελέγχους θα έκανες;** Πρόσφατα δεδομένα; υπάρχουν κλειστοί χώροι που δεν είναι δημόσια προσβάσιμοι; το οδικό δίκτυο είναι πλήρες; το CRS επιτρέπει σωστή μέτρηση; υπάρχουν πηγές και άδειες χρήσης;

**Δ. Τι παραδίδεις;** Ένα σύνολο περιοχών που ικανοποιούν το κριτήριο, έναν χάρτη και σύντομη εξήγηση των περιορισμών. Μην παρουσιάζεις την ανάλυση ως οριστική χωροθέτηση πάρκου χωρίς κοινωνικά, πολεοδομικά και περιβαλλοντικά κριτήρια.

## Έλεγξε όσα έμαθες

1. Ποια είναι η βασική διαφορά ανάμεσα στο GIS και στο QGIS;
2. Πότε είναι χρήσιμο να αποτυπώσω ένα κτίριο ως σημείο και πότε ως πολύγωνο;
3. Τι περιέχει ένα γνώρισμα (attribute);
4. Ένα raster χρωματισμένο πράσινο περιέχει υποχρεωτικά την τιμή «πράσινο»;
5. Γιατί η «απόσταση 300» είναι ασαφής χωρίς CRS και μονάδες;
6. Ποια είναι η διαφορά μεταξύ ενός αρχείου `.gpkg` και ενός έργου `.qgz`;
7. Μπορώ να χρησιμοποιήσω δεδομένα γενικευμένων συνόρων για τοπογραφική οριοθέτηση ακινήτου; Γιατί;
8. Γιατί πρέπει να ελέγχω την ημερομηνία και την άδεια ενός συνόλου δεδομένων;

:::{dropdown} Ενδεικτικές απαντήσεις — άνοιξέ τες αφού δοκιμάσεις

## Μπορώ να συνεχίσω όταν…

- [ ] Εξηγώ με δικά μου λόγια τι είναι ένα GIS.
- [ ] Αναγνωρίζω σημείο, γραμμή, πολύγωνο και raster.
- [ ] Ξέρω γιατί απαιτούνται CRS, μονάδες και έλεγχος πηγών.
- [ ] Περιγράφω τα βασικά στάδια μιας εργασίας GIS.
- [ ] Κατανοώ ότι ένας ωραίος χάρτης δεν εγγυάται ορθότητα.
