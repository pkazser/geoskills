# GQ-START — Εισαγωγή στα Γεωγραφικά Συστήματα Πληροφοριών

**Πριν ανοίξουμε το QGIS, μαθαίνουμε να σκεφτόμαστε γεωγραφικά.**

Ένας χάρτης μπορεί να είναι πολύ όμορφος αλλά να απαντά σε λάθος ερώτημα. Ένα GIS μας βοηθά να εργαστούμε συστηματικά με πληροφορίες που έχουν θέση στον χώρο, να τις ελέγξουμε και να εξαγάγουμε τεκμηριωμένα συμπεράσματα.

**Χρόνος:** 90–120 λεπτά · **Προαπαιτούμενα:** κανένα · **Λογισμικό:** δεν απαιτείται για αυτή την ενότητα.

## Τι θα γνωρίζεις στο τέλος

- Να εξηγείς τι είναι GIS και σε τι διαφέρει από ένα λογισμικό χαρτογράφησης ή μια εφαρμογή πλοήγησης.
- Να αναγνωρίζεις πότε ένα γεωγραφικό ερώτημα χρειάζεται χωρική ανάλυση.
- Να ξεχωρίζεις σημεία, γραμμές, πολύγωνα και ψηφιδωτά δεδομένα (raster).
- Να καταλαβαίνεις την έννοια των γεωγραφικών επιπέδων, των γνωρισμάτων, των συντεταγμένων και της ποιότητας των δεδομένων.
- Να οργανώνεις νοητικά τα βασικά στάδια μιας εργασίας GIS και να χρησιμοποιείς το απαραίτητο λεξιλόγιο.
