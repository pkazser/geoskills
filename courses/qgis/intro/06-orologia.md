# 6. Το βασικό λεξιλόγιο ενός χρήστη GIS

Αυτός ο πίνακας είναι το **βασικό λεξιλόγιο του GeoSkills**. Δεν χρειάζεται να απομνημονεύσεις όλους τους όρους από τώρα. Επιστρέφεις εδώ όποτε συναντάς έναν άγνωστο όρο.

| Όρος | Τι σημαίνει απλά |
|---|---|
| GIS / ΣΓΠ | Σύστημα για διαχείριση, ανάλυση και παρουσίαση πληροφοριών με γεωγραφική θέση |
| QGIS | Ελεύθερο λογισμικό ανοιχτού κώδικα για εργασίες GIS |
| Γεωχωρικό δεδομένο | Πληροφορία που συνδέεται με θέση ή περιοχή στον χώρο |
| Αντικείμενο (feature) | Μια εγγραφή με γεωμετρία, π.χ. ένα σχολείο ή αγροτεμάχιο |
| Γεωμετρία (geometry) | Χωρική αναπαράσταση αντικειμένου: σημείο, γραμμή, πολύγωνο |
| Vector / διανυσματικό | Αναπαράσταση μέσω γεωμετρικών αντικειμένων |
| Raster / ψηφιδωτό | Δεδομένα οργανωμένα σε πλέγμα κελιών |
| Pixel / κελί | Βασική χωρική μονάδα raster, με αριθμητική ή κατηγορική τιμή |
| Επίπεδο (layer) | Σύνολο δεδομένων που προβάλλεται και οργανώνεται στο GIS |
| Γνώρισμα (attribute) | Περιγραφική τιμή ενός αντικειμένου, π.χ. όνομα ή κατηγορία |
| Πεδίο (field) | Στήλη πίνακα γνωρισμάτων |
| Πίνακας γνωρισμάτων | Οι εγγραφές και οι περιγραφικές τιμές αντικειμένων |
| Συντεταγμένες | Αριθμοί που ορίζουν τη θέση σε συγκεκριμένο σύστημα αναφοράς |
| CRS | Σύστημα αναφοράς συντεταγμένων: ορίζει πώς ερμηνεύονται οι συντεταγμένες |
| EPSG | Κωδικός αναγνώρισης ορισμού συστήματος αναφοράς, π.χ. EPSG:4326 |
| WGS 84 (EPSG:4326) | Συνήθες γεωγραφικό CRS με γωνιακές συντεταγμένες (μοίρες) |
| ΕΓΣΑ87 (EPSG:2100) | Προβολικό CRS που χρησιμοποιείται ευρέως στην Ελλάδα, με επίπεδες συντεταγμένες σε μέτρα |
| Προβολή | Μαθηματικός τρόπος απεικόνισης της καμπύλης Γης σε επίπεδο χάρτη |
| Επαναπροβολή | Μετατροπή συντεταγμένων ενός συνόλου από ένα CRS σε άλλο |
| Κλίμακα χάρτη | Σχέση απόστασης στον χάρτη προς αντίστοιχη απόσταση στο έδαφος |
| Χωρική ανάλυση | Το μέγεθος κελιού / επίπεδο λεπτομέρειας, αναλόγως δεδομένων |
| Συμβολισμός | Ρύθμιση χρωμάτων, γραμμών, συμβόλων και κατηγοριών εμφάνισης |
| Θεματικός χάρτης | Χάρτης που παρουσιάζει μια ιδιότητα ή φαινόμενο με συγκεκριμένο συμβολισμό |
| Ψηφιοποίηση | Δημιουργία γεωμετριών με χειροκίνητη ή ημιαυτόματη σχεδίαση |
| Γεωαναφορά | Συσχέτιση εικόνας ή δεδομένων με πραγματικές γεωγραφικές συντεταγμένες |
| Buffer / ζώνη εγγύτητας | Περιοχή μέσα σε ορισμένη απόσταση από αντικείμενο |
| Intersection / τομή | Γεωμετρικό κοινό μέρος δύο περιοχών ή συνόλων |
| Clip / αποκοπή | Περιορισμός δεδομένων στα όρια συγκεκριμένης περιοχής |
| Join / σύνδεση | Συσχέτιση εγγραφών με κοινό πεδίο ή χωρική σχέση |
| Τοπολογία | Χωρικές σχέσεις και κανόνες όπως σύνδεση, επικάλυψη ή μη ύπαρξη κενών |
| NoData | Ειδική ένδειξη ότι δεν υπάρχει έγκυρη τιμή σε κελί raster |
| Μεταδεδομένα | Πληροφορίες για πηγή, χρόνο, ποιότητα, CRS, χρήση και περιορισμούς |
| GeoPackage (.gpkg) | Σύγχρονο, φορητό αρχείο βάσης γεωχωρικών δεδομένων |
| Έργο QGIS (.qgz) | Αρχείο ρυθμίσεων έργου και αναφορών σε πηγές δεδομένων |
| WMS | Διαδικτυακή υπηρεσία χαρτογραφικών εικόνων |
| WFS | Διαδικτυακή υπηρεσία διανυσματικών γεωγραφικών αντικειμένων |

## Τρεις κρίσιμες διακρίσεις

1. **GIS ≠ QGIS:** το πρώτο είναι το ευρύτερο σύστημα, το δεύτερο ένα εργαλείο.
2. **Γεωχωρικά δεδομένα ≠ χάρτης:** ο χάρτης είναι τρόπος παρουσίασης/ερμηνείας των δεδομένων.
3. **CRS έργου ≠ αλλαγή των αρχικών συντεταγμένων:** η εμφάνιση επιπέδων μαζί στην οθόνη δεν σημαίνει ότι τα αρχεία άλλαξαν μόνιμα CRS.

:::{note} Τι ακολουθεί
Στο GQ02 θα εξηγήσουμε αναλυτικά τι συμβαίνει με γεωγραφικές και προβολικές συντεταγμένες, μονάδες, EPSG και σωστούς μετασχηματισμούς. Εδώ αρκεί να ξέρεις **γιατί είναι απαραίτητο να ελέγχεις το CRS**.
:::
