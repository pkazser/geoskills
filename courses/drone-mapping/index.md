# Drone Mapping Core

Η εκπαιδευτική διαδρομή Drone Mapping Core οργανώνει τα μαθήματα DM00–DM03 σε διαδοχική πορεία από τις βασικές έννοιες και την ασφάλεια έως τον σχεδιασμό και τον αρχικό έλεγχο μιας υποθετικής αποστολής.

## Διαθέσιμα ως Preview v0.1

- [DM00 — Εισαγωγή στα drones και στη χαρτογράφηση](dm00/index.md)
- [DM01 — Ασφαλής και υπεύθυνη εκτέλεση χαρτογραφικής αποστολής](dm01/index.md)
- [DM02 — Σχεδιασμός φωτογραμμετρικής πτήσης](dm02/index.md)
- [DM03 — Εκτέλεση αποστολής και αρχικός ποιοτικός έλεγχος φωτογραφιών](dm03/index.md)

Τα DM04–DM05 είναι προγραμματισμένα και δεν αποτελούν μέρος της παρούσας δοκιμαστικής ενσωμάτωσης.
