# Καρτέλα 04 — Από τον σχεδιασμό στο ασφαλές κλείσιμο αποστολής

**GeoSkills · Ενιαία πρακτική άσκηση DM00.4 · Εκπαιδευτική προσομοίωση, όχι πραγματική άδεια πτήσης**

**Σενάριο:** Αγρός 25 ha με γειτονικό αγροτικό δρόμο, δέντρο κοντά στην απογείωση, ηλεκτρικά καλώδια, πιθανή παρουσία πεζών και γειτονική αυλή. Στην αρχή **δεν είναι γνωστά** ακριβής τοποθεσία, ημερομηνία/ώρα, drone/κλάση, χειριστής/προσόντα, άδειες και καιρός.

> Κρίσιμο: επειδή βασικά στοιχεία λείπουν, η αρχική εκπαιδευτική απόφαση είναι **ΑΝΑΜΟΝΗ ΕΛΕΓΧΩΝ**, όχι GO.

## Β — Κατά την πτήση, σε ανεξάρτητο υποθετικό σενάριο (12 μονάδες)

Θεώρησε **μόνο για την άσκηση** ότι οι απαιτούμενοι έλεγχοι της ενότητας Α ολοκληρώθηκαν επιτυχώς και ξεκίνησε νόμιμη πτήση. Συμπλήρωσε την εξέλιξη.

| Νέα πληροφορία | Γεγονός έναντι υπόθεσης | Ποιος κινδυνεύει; | Απόφαση και τι επανεξετάζω |
|---|---|---|---|
| **Παράδειγμα: πεζός στο Home Point** | Γεγονός: πεζός κοντά στην ανάκτηση. Άγνωστο αν θα εισέλθει στην προσγείωση | Πεζός | Δεν θεωρώ ασφαλές το Home Point χωρίς νέο έλεγχο· προστατεύω τρίτους |
| Ισχυρότερος αντίθετος άνεμος, μειωμένο ενεργειακό περιθώριο | | | |
| Παγωμένη τηλεμετρία, χωρίς επιβεβαιωμένη απώλεια C2 | | | |
| Ακούγεται ελικόπτερο, πορεία άγνωστη | | | |

**Τελική απόφαση Β:** Η εικόνα και η τηλεμετρία επανήλθαν, αλλά πεζός παραμένει κοντά στο Home Point. Συνεχίζουμε αυτομάτως τις λήψεις; Αιτιολόγησε: ______________________

## Γ — Μετά την προσγείωση (12 μονάδες)

Η κάρτα περιέχει 270 συνθετικές φωτογραφίες. Οι 101–103 αποτυπώνουν τμήμα γειτονικής αυλής (η 102 πιθανώς αναγνωρίσιμο πρόσωπο, η 103 ευανάγνωστη πινακίδα). Υπάρχει πιθανό κενό κάλυψης και μη αξιολογημένη ένδειξη εξοπλισμού.

| Τι ελέγχω | Τεκμήριο / αποτέλεσμα | Εκκρεμότητα / απόφαση |
|---|---|---|
| **Παράδειγμα: πλήθος εικόνων** | Εμφανίζονται 270 αρχεία | Το πλήθος δεν πιστοποιεί κάλυψη ή ευκρίνεια |
| Ασφαλής κατάσταση drone και μπαταρίας | | |
| Άνοιγμα αρχείων, ποιότητα και φωτογραμμετρική κάλυψη | | |
| Ασφαλές αντίγραφο / διαχείριση κάρτας | | |
| Τυχόν προσωπικά δεδομένα και αιτήματα κοινοποίησης | | |
| Ημερολόγιο, εκκρεμότητες, επόμενος υπεύθυνος ελέγχου | | |

**Απόφαση Γ — Τρία ανεξάρτητα πεδία κατάστασης (συμπλήρωσε όλα):**

- **Πτήση:** Ολοκληρώθηκε / Δεν έχει επιβεβαιωθεί. Τεκμήριο: __________
- **Εργασία πεδίου:** Έκλεισε χωρίς εκκρεμότητες / Έκλεισε με καταγεγραμμένες εκκρεμότητες / Δεν έχει κλείσει. Αιτία: __________
- **Δεδομένα:** Έτοιμα για επεξεργασία / Υπό έλεγχο / Ακατάλληλα προς το παρόν. Τεκμήριο: __________

**Υπεύθυνος και επόμενο βήμα για κάθε εκκρεμότητα:** __________________________

Οι καταστάσεις δεν είναι αμοιβαία αποκλειόμενες: μια πτήση μπορεί να έχει ολοκληρωθεί ενώ η καταλληλότητα των δεδομένων παραμένει υπό έλεγχο.

## Δ — Συνολική σύνθεση (4 μονάδες)

Σε 5–7 προτάσεις εξήγησε γιατί (i) η επιτρεπτή πτήση, (ii) η ασφαλής ολοκλήρωση, (iii) η τεχνική επάρκεια των φωτογραφιών και (iv) η επιτρεπτή διάθεση εικόνων αποτελούν διακριτούς ελέγχους.

## Κλίμακα αξιολόγησης (40 μονάδες)

| Τμήμα | Μονάδες |
|---|---:|
| Α — Προπτητική νομιμότητα και ασφάλεια | 12 |
| Β — Αντίδραση σε μεταβολές | 12 |
| Γ — Αρχεία, ιδιωτικότητα και κλείσιμο | 12 |
| Δ — Συνολική αιτιολόγηση | 4 |
| **Σύνολο** | **40** |

**Εσωτερική πρόταση αξιολόγησης:** 32/40 με επιτυχία στις κρίσιμες πύλες ασφάλειας. Είναι **διδακτικό** όριο GeoSkills, όχι πιστοποίηση. Ανεξάρτητα από τη βαθμολογία, χρειάζεται επανεξέταση αν ο φοιτητής εγκρίνει απογείωση χωρίς απαιτούμενους ελέγχους, αγνοεί άμεσο κίνδυνο σύγκρουσης ή δημοσιεύει ανεξέλεγκτα εικόνες πιθανώς αναγνωρίσιμων τρίτων.

**Α:** ΑΝΑΜΟΝΗ ΕΛΕΓΧΩΝ επειδή δεν υπάρχουν συγκεκριμένα δεδομένα drone, θέσης, προσόντων, DAGR και καιρού. Το γενικό σενάριο δεν είναι σχέδιο πραγματικής απογείωσης.

**Β:** Η νέα παρουσία πεζού αλλάζει την ασφάλεια ανάκτησης· ο αντίθετος άνεμος απαιτεί επανεκτίμηση διαθέσιμης ενέργειας· παγωμένη τηλεμετρία δεν αποδεικνύει απώλεια C2· η εμφάνιση επανδρωμένου αεροσκάφους απαιτεί επείγουσα προτεραιότητα αποφυγής σύγκρουσης. Δεν θεωρούμε το RTH καθολικά ασφαλές. Η επανεμφάνιση ενδείξεων δεν αρκεί για αυτόματη συνέχιση.

**Γ:** Πτήση: ολοκληρώθηκε· εργασία πεδίου: έκλεισε με καταγεγραμμένες εκκρεμότητες μόνον εφόσον ο εξοπλισμός και τα αρχεία έχουν ασφαλιστεί και έχει ανατεθεί ο επόμενος έλεγχος· δεδομένα: υπό έλεγχο. Το πλήθος 270 αρχείων δεν αποδεικνύει καλή φωτογραμμετρική κάλυψη. Επισημαίνουμε το κενό, ελέγχουμε φυσική κατάσταση και αρχεία, τηρούμε αντίγραφα και αποφεύγουμε άκριτη δημοσίευση λήψεων με πιθανώς προσωπικά δεδομένα. Η εργασία πεδίου μπορεί να κλείσει **με καταγεγραμμένες εκκρεμότητες**, χωρίς να σημαίνει ότι τα δεδομένα είναι έτοιμα.

**Δ:** Διακρίνουμε επιχειρησιακή νομιμότητα, ασφάλεια, ποιότητα δεδομένων και κανόνες επεξεργασίας/δημοσίευσης. Οι τέσσερις έλεγχοι δεν υποκαθιστούν ο ένας τον άλλο.

**Βαθμολόγηση:** Α: 3 μονάδες κατηγορία/ρόλοι, 3 DAGR, 3 πεδίο/καιρός, 3 τεκμηριωμένη NO-GO/αναμονή. Β: 3 τρίτοι, 3 καιρός/ενέργεια, 3 αξιοπιστία ενδείξεων, 3 ελικόπτερο/ιεράρχηση. Γ: 3 εξοπλισμός, 3 φωτογραφίες/κάλυψη, 3 ασφάλεια δεδομένων, 3 τεκμηρίωση/κατάσταση. Δ: 4 μονάδες για σαφή διάκριση και των τεσσάρων ελέγχων.

Για κάθε κριτήριο των 3 μονάδων: **3** όταν υπάρχει σωστή απόφαση και συγκεκριμένο τεκμήριο/αιτιολόγηση, **2** όταν η απόφαση είναι ορθή αλλά η τεκμηρίωση ελλιπής, **1** όταν αναγνωρίζεται μόνο ένα σχετικό στοιχείο, **0** όταν λείπει ή είναι επικίνδυνα λανθασμένη. Για το μέρος Δ αποδίδεται μία μονάδα για καθεμία από τις τέσσερις διακριτές διαστάσεις που εξηγούνται σωστά. Η αξιολόγηση είναι εκπαιδευτική, όχι πιστοποίηση χειριστή.

## Σύντομος έλεγχος ολοκλήρωσης της καρτέλας

- Έχω διαχωρίσει πραγματικά στοιχεία από υποθέσεις και έχω αιτιολογήσει κάθε απόφαση.
- Δεν έχω επιτρέψει πραγματική απογείωση επειδή το παράδειγμα υποθέτει ότι ολοκληρώθηκαν έλεγχοι.
- Δεν θεωρώ το RTH αυτόματα ασφαλές ούτε την παγωμένη τηλεμετρία τρέχουσα πληροφορία.
- Έχω καταγράψει χωριστά το τέλος της πτήσης, το κλείσιμο πεδίου και την καταλληλότητα των δεδομένων.
- Έχω ορίσει επόμενο έλεγχο και υπεύθυνο για κάθε εκκρεμότητα.
