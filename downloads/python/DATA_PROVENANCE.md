# GeoPython Core — απογραφή προέλευσης δεδομένων

Η απογραφή αφορά τα datasets που διανέμονται με το GeoPython Core. Τα GP01–GP10 είναι δικά μας συνθετικά εκπαιδευτικά datasets και δεν περιέχουν γνωστή εξωτερική πηγή ή δικαίωμα τρίτου. Δεν αντιπροσωπεύουν πραγματική απογραφή ή πραγματικές εγκαταστάσεις.

## Άδεια GP01–GP10

Τα datasets GP01–GP10 διανέμονται με [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Η αναδιανομή, τροποποίηση και εμπορική χρήση επιτρέπονται υπό τους όρους της άδειας. Απαιτούνται αναφορά δημιουργού, σύνδεσμος προς την άδεια και επισήμανση των τροποποιήσεων.

Προτεινόμενη αναφορά: **GeoSkills — GeoPython Core, συνθετικά εκπαιδευτικά γεωχωρικά δεδομένα.**

Πηγή: [GeoPython Core στο GeoSkills](https://pkazser.github.io/geoskills/courses/python/).
