# GeoPython Core — αρχεία υποστήριξης

Ο φάκελος περιέχει τα εκπαιδευτικά δεδομένα και τα starter notebooks των GP00–GP10 και του Core Capstone.

## Κατάσταση αδειοδότησης

Τα δεδομένα του source repository περιγράφονται ως μικρά, συνθετικά ή εκπαιδευτικά σύνολα, όμως δεν βρέθηκε ενιαίο, ρητό αρχείο άδειας για όλα τα datasets GP01–GP10. Επομένως δεν αποδίδεται αυθαίρετα άδεια CC BY 4.0 σε ολόκληρο το πακέτο. Η προέλευση, τα δικαιώματα αναδιανομής και η τελική άδεια κάθε συνόλου πρέπει να επιβεβαιωθούν πριν από δημόσια δημοσίευση.

Το README του Core Capstone δηλώνει ότι τα δεδομένα είναι εκπαιδευτικά και δεν αντιπροσωπεύουν πραγματική απογραφή ή πραγματικό επίπεδο δημόσιων υπηρεσιών. Η ίδια σαφής σήμανση πρέπει να διατηρηθεί και στις σελίδες των υπόλοιπων ενοτήτων.

Τα notebooks στον φάκελο `notebooks/starter/` είναι σκόπιμα ημιτελή φύλλα εργασίας. Τα notebooks λύσεων του source repository δεν μεταφέρθηκαν στη δημόσια δομή.
