# GeoSkills — GQ-START / Γρήγορο δελτίο ορολογίας

Αναφορά: Κεφάλαιο 6 — Το λεξιλόγιο της Γεωπληροφορικής. Δεν υποκαθιστά τα αναλυτικά μαθήματα.

| Διάκριση | Τι θυμάμαι |
|---|---|
| GIS / QGIS | Το σύστημα / το συγκεκριμένο λογισμικό |
| Γεωμετρία / γνώρισμα | Θέση και σχήμα / περιγραφική πληροφορία |
| Vector / raster | Αντικείμενα με γεωμετρίες / πλέγμα κελιών |
| Αριθμητική τιμή raster / χρώμα | Δεδομένο / επιλογή εμφάνισης |
| Geographic / projected CRS | Συνήθως μοίρες / επίπεδες συντεταγμένες με καθορισμένες μονάδες |
| EPSG:4326 / EPSG:2100 | WGS 84, μοίρες / ΕΓΣΑ87, μέτρα |
| CRS έργου / CRS αρχείου | Εμφάνιση / αποθηκευμένες συντεταγμένες |
| Buffer / clip / join | Ζώνη απόστασης / αποκοπή / σύνδεση γνωρισμάτων |
| .gpkg / .qgz | Δεδομένα / έργο QGIS και συνδέσεις |
| WMS / WFS | Εικόνα χάρτη / πρόσβαση σε αντικείμενα |
| Ανάλυση / ακρίβεια | Χωρική λεπτομέρεια / εγγύτητα σε θέσεις αναφοράς |

Πριν από κάθε εργασία: **ερώτημα → δεδομένα → CRS → μέθοδος → έλεγχος → τεκμηρίωση**.
