# GQ06 thematic zones v0.1

Το `GQ06_thematic_zones_v0.1.gpkg` είναι μικρό, συνθετικό εκπαιδευτικό σύνολο δεδομένων για το GQ06 — Θεματική χαρτογραφία και συμβολισμός στο QGIS.

Περιέχει το πολυγωνικό layer `thematic_zones` σε EPSG:2100. Οι 16 περιοχές δεν αποτελούν πραγματική δημοτική απογραφή. Τα πεδία `population`, `area_km2` και `density_km2` έχουν δημιουργηθεί αποκλειστικά για την άσκηση και η πυκνότητα υπολογίζεται ως πληθυσμός ανά km².

Η προέλευση είναι εσωτερική συνθετική δημιουργία GeoSkills. Δεν αποδίδεται νέα άδεια χρήσης χωρίς ξεχωριστή έγκριση.
