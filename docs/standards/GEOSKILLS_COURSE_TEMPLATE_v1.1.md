# GeoSkills Course Template v1.1

## Changelog v1.0 → v1.1

- Προστέθηκε ρητή εκπαιδευτική αυτοτέλεια και κανόνας ότι οι εξωτερικές πηγές είναι συμπληρωματικές.
- Προστέθηκε πρότυπο στοχευμένης παραπομπής με γλώσσα, συγκεκριμένο τμήμα και οδηγία παρατήρησης.
- Προστέθηκαν οδηγίες προσαρμογής για εννοιολογικά, λογισμικά, πεδίου και Capstone μαθήματα.
- Προστέθηκαν κοινά release gates και browser statuses με σαφή διάκριση `NOT TESTED`/`CONDITIONAL GO`.
- Οι φωτογραφικές προτεραιότητες χρησιμοποιούν Α/Β/Γ και τα QA ευρήματα P0–P3.

Το template είναι αφετηρία, όχι υποχρεωτική αντιγραφή του FS00. Χρησιμοποίησε μόνο τις ενότητες, εικόνες, αρχεία και δραστηριότητες που χρειάζεται ο συγκεκριμένος μαθησιακός στόχος.

## 1. Προσαρμογή ανά τύπο μαθήματος

- **Εννοιολογικό:** κράτησε ορισμούς, νοητικά μοντέλα, αντιπαραδείγματα και σύντομες δραστηριότητες. Τα SVG/φωτογραφίες είναι προαιρετικά.
- **Λογισμικό:** πρόσθεσε έκδοση εργαλείου, reproducible βήματα, μικρό dataset και screenshots μόνο όπου βοηθούν. Δεν απαιτείται photo register.
- **Εργασία πεδίου:** πρόσθεσε ασφάλεια, εξοπλισμό, συνθήκες, όρια μοντέλου, πραγματικές/συνθετικές εικόνες και checks παρατηρήσεων.
- **Capstone:** πρόσθεσε deliverables, κριτήρια αξιολόγησης, checkpoints και τεκμηρίωση αποφάσεων. Hidden answers ή quiz μπαίνουν μόνο αν υπηρετούν τον στόχο.

Για κάθε τύπο, ο βασικός στόχος πρέπει να επιτυγχάνεται από το ίδιο το μάθημα. Οι εξωτερικές πηγές είναι συμπληρωματικές.

## 2. Προτεινόμενη δομή φακέλου

```text
courses/<domain>/<course>/
├── index.md
├── assets/                 # μόνο αν χρειάζονται
│   ├── figures/            # μόνο αν υπάρχουν figures
│   ├── photo_placeholders/ # μόνο αν λείπουν πραγματικές φωτογραφίες
│   └── photos/             # μόνο αν υπάρχουν αδειοδοτημένες εικόνες
├── <course>_Photo_Replacement_Register.csv # προαιρετικό
├── <course>_Real_Photos_Pending.md         # προαιρετικό
└── <course>_Targeted_References.md         # προαιρετικό
```

Μην προσθέτεις αρχεία μόνο για να ταιριάξεις το FS00. Η ανάγκη τεκμηριώνεται από το αντικείμενο και τον στόχο.

## 3. `index.md` skeleton

```md
# <COURSE-ID> — <Τίτλος>

**Διαδρομή:** <domain> · **Έκδοση:** <version>
**Κατάσταση:** προσχέδιο / προς αξιολόγηση / εγκεκριμένο.
**Μαθησιακή αποστολή:** <τι θα μπορεί να κάνει ο εκπαιδευόμενος>.
**Προαπαιτούμενα:** <κανένα ή συγκεκριμένα μαθήματα/δεξιότητες>.

> **Σημείωση:** Δήλωσε αν παραδείγματα, εικόνες ή διαδικασίες είναι συνθετικά,
> ενδεικτικά, συγκεκριμένα για μοντέλο ή εγκεκριμένα για πραγματική χρήση.

## Πώς θα εργαστείς

Σύντομη εισαγωγή, στόχοι, χρόνος και τρόπος αξιοποίησης. Η βασική έννοια
πρέπει να εξηγείται εδώ, όχι μόνο σε εξωτερικό link.

## <COURSE-ID>.1 — <Πρώτη μαθησιακή ενότητα>

### <Υποενότητα>

Εισαγωγική θεωρία με ορισμούς, όρια και σύνδεση με τον στόχο.
```

## 4. Instructional SVG figure

```md
:::{figure} assets/figures/<instructional-diagram>.svg
:alt: <Ουσιαστική περιγραφή του τι δείχνει το διάγραμμα>
:width: 100%

Σχήμα <ID>. <Λεζάντα: τι πρέπει να παρατηρήσει ο εκπαιδευόμενος>.
:::
```

Το responsive width δεν αλλάζει τη γεωμετρία. Έλεγξε ότι το figure δεν περιορίζεται από inline `max-height: 1.2em` και ότι δεν δημιουργεί overflow σε mobile.

## 5. Φωτογραφία και placeholder

### Αδειοδοτημένη τοπική φωτογραφία

```md
![<Ουσιαστικό alt text>](assets/photos/<photo>.jpg)

**Φωτογραφία <ID>.** <Τι δείχνει και γιατί έχει μαθησιακή αξία>. Πηγή:
[<δημιουργός/πηγή>](<source-url>) · [<άδεια>](<license-url>). Τοπικό αντίγραφο
χρησιμοποιείται για αξιόπιστο CI build.
```

### Placeholder

```md
![Σχηματική αναπαράσταση: <ID>](assets/photo_placeholders/<ID>.svg)

**Εκκρεμεί πραγματική φωτογραφία — <ID>.** *Ζητούμενη λήψη:* <συγκεκριμένο
κάδρο, αντικείμενα, μαθησιακή έννοια και περιορισμοί προσωπικών δεδομένων>.
```

Στο register χρησιμοποίησε φωτογραφική προτεραιότητα **Α**, **Β** ή **Γ**:

- Α: υποστηρίζει βασική έννοια/πρακτική και ιδανικά προηγείται της πρώτης έκδοσης.
- Β: σημαντική ενίσχυση που μπορεί τεκμηριωμένα να μετατεθεί.
- Γ: συμπληρωματική ή αισθητική εικόνα για μεταγενέστερη έκδοση.

Η Α/Β/Γ δεν είναι P0/P1/P2/P3. Τα P0–P3 αφορούν μόνο QA findings.

## 6. Στοχευμένη εξωτερική παραπομπή

```md
> **Συμπληρωματική πηγή — Αγγλικά.** [<Επίσημη τεκμηρίωση>](<url>),
> ενότητα <chapter/section/figure/page>. Παρατήρησε <συγκεκριμένο στοιχείο>.
> Η βασική έννοια εξηγείται στο παρόν μάθημα.
```

Αν η πηγή είναι ελληνική, δήλωσε `Ελληνικά`. Μην χρησιμοποιείς αόριστο “δες το manual” χωρίς συγκεκριμένο τμήμα και οδηγία παρατήρησης.

## 7. Δραστηριότητα και hidden answer

```md
### Δραστηριότητα

<Συγκεκριμένη ερώτηση ή εργασία με αναμενόμενο παραδοτέο.>

<details><summary>Ενδεικτική απάντηση</summary>

<Σύντομη απάντηση και αιτιολόγηση.>

</details>
```

Χρησιμοποίησε hidden answer μόνο όταν βοηθά την αυτοαξιολόγηση. Σε Capstone ή αυθεντική εργασία μπορεί να παραλειφθεί.

```md
### Τελικός έλεγχος

- [ ] <Μπορώ να εξηγήσω ...>
- [ ] <Μπορώ να αναγνωρίσω ...>
- [ ] <Κατέγραψα τις εκκρεμότητες ...>
```

## 8. Release gates και status

```text
Content Approval: PASS / FAIL / NOT TESTED
Technical QA: PASS / FAIL / NOT TESTED
Release Approval: GO / CONDITIONAL GO / NO-GO
Published Verification: PASS / FAIL / NOT TESTED
```

`NOT TESTED` δεν είναι PASS. `CONDITIONAL GO` απαιτεί υπεύθυνο, αιτιολόγηση, ακριβές scope μη ολοκληρωμένου ελέγχου και ημερομηνία επανελέγχου. Δεν επιτρέπεται exception για P0, P1 ή μη εγκεκριμένο περιεχόμενο.

## 9. Παραπομπές και handoff

```md
## Στοχευμένες πηγές

- [<Επίσημη τεκμηρίωση>](<url>) — <γλώσσα>, <συγκεκριμένο τμήμα>, <τι ελέγχθηκε>.
```

Πριν από QA συμπλήρωσε μόνο ό,τι χρειάζεται:

- Content Approval owner/date: <τιμή>
- Scientific sources/checkpoints: <τιμή>
- Photo/license register: <path ή N/A>
- Known findings: <P0–P3 ή none>
- Expected counters: <sections, figures, images, answers>
- QA worktree/branch/commit: <τιμές>
